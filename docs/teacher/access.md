# 1. 홈페이지 접속과 회원가입

## 접속 주소

**`https://interedu.ai.kr`**

프로그램을 둘러보는 것은 로그인 없이도 가능합니다.
다만 수강 신청, 수강바구니, 마이페이지를 이용하시려면 회원가입이 필요합니다.

## 회원가입

홈페이지 오른쪽 위의 **로그인**을 누른 뒤 **회원가입**을 선택합니다.

![회원가입 정보 입력 화면](/images/teacher/teacher-02-signup.png)

### 1단계. 이용약관 동의

약관 내용을 확인하고 필수 항목에 동의합니다.

### 2단계. 정보 입력

| 항목 | 입력 방법 |
| --- | --- |
| **아이디** | **8자 이상**으로 입력한 뒤 **중복확인** 버튼을 누릅니다. 글자 수 상한은 없습니다. |
| **비밀번호** | 영문, 숫자, 특수문자(`!@#$%^&*`)를 포함하여 8자에서 20자 사이로 입력합니다. |
| **비밀번호 확인** | 위와 동일하게 한 번 더 입력합니다. |
| **이름** | 실명을 입력합니다. |
| **이메일** | 입력한 뒤 **중복확인** 버튼을 누릅니다. 안내 메일이 이 주소로 발송됩니다. |
| **휴대폰** | `010-1234-5678` 형식으로 입력합니다. |
| **유형** | **교사** 또는 **일반** 중에서 선택합니다. |

### 유형별 추가 입력

**교사**를 선택한 경우

- **학교 검색** 버튼을 눌러 학교를 검색합니다.
- 학교를 선택하면 학교코드와 학교명이 자동으로 입력됩니다.

**일반**을 선택한 경우

- **기관명**을 입력합니다. 선택 항목입니다.

::: warning 중복확인을 완료해야 가입할 수 있습니다
아이디와 이메일은 **중복확인**을 눌러 사용 가능 안내를 받아야 가입이 진행됩니다.
중복확인 후 내용을 수정하면 확인이 해제되므로 다시 눌러 주세요.
:::

마지막으로 **회원가입**을 누르면 가입이 완료되고 로그인 화면으로 이동합니다.

::: tip 강사 계정과는 다릅니다
수업을 진행하는 강사로 가입하시려면 [강사 설명서](/tutor/)를 확인해 주세요. 접속 주소와 가입 절차가 다릅니다.
:::

## 로그인

홈페이지 오른쪽 위의 **로그인**을 누르고 아이디와 비밀번호를 입력합니다.

## 아이디와 비밀번호 찾기

로그인 화면 아래의 **아이디 찾기** 또는 **비밀번호 찾기**를 이용합니다.

- **아이디 찾기** : 이름과 휴대폰 번호를 입력합니다.
- **비밀번호 찾기** : 아이디와 가입 시 입력한 이메일을 입력한 뒤, 메일로 받은 링크에서 새 비밀번호를 설정합니다.

::: tip 메일이 도착하지 않는 경우
먼저 스팸메일함을 확인해 주세요. 보내는 사람은 **인터에듀**로 표시됩니다.
:::

## 비밀번호 변경

로그인 후 **마이페이지 → 계정 정보**에서 변경할 수 있습니다.
현재 비밀번호를 입력한 뒤 새 비밀번호를 두 번 입력하고 **비밀번호 변경**을 누릅니다.
