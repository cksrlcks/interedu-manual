# 이 설명서에 대하여

인터에듀는 **수업을 신청하는 분**, **수업을 진행하는 분**, **서비스를 운영하는 분**이 각각 다른 화면을 사용합니다.
하시려는 일에 따라 아래에서 해당하는 설명서를 선택해 주세요.

## 어떤 설명서를 보아야 하는지

| 해당하는 경우 | 부르는 이름 | 사용하는 주소 | 설명서 |
| --- | --- | --- | --- |
| 학교나 기관으로 수업을 하러 나가시는 강사·공방·단체 | **강사** | `interedu.ai.kr/tutor` | [강사 설명서](/tutor/) |
| 학교나 기관에서 수업을 신청하시는 선생님 | **선생님** | `interedu.ai.kr` | [선생님 설명서](/teacher/) |
| 인터에듀 운영을 담당하시는 직원 | **관리자** | `interedu.ai.kr/admin` | [관리자 설명서](/admin/) |

::: tip 설명서에서 쓰는 두 가지 호칭
수업을 진행하시는 분은 개인·공방·단체를 구분하지 않고 모두 **강사**로 표기합니다.
수업을 신청하시는 분은 **선생님**으로 표기합니다.
:::

## 전체 진행 과정

한 건의 수업은 다음 순서로 진행됩니다.

1. **선생님**이 프로그램을 선택해 수강 신청을 합니다.
2. **관리자**가 신청을 확인하고 일정을 확정한 뒤, 강사를 배정하고 견적서를 발행합니다.
3. 관리자가 신청을 확정하면 **강의가 자동으로 생성**되고 양쪽에 안내 메일이 발송됩니다.
4. **강사**가 배정된 강의를 확인하고 준비 서류를 내려받은 뒤 수업을 진행합니다.
5. 수업 후 **강사**가 참여인원과 활동 사진을 등록하고 활동보고서를 생성합니다.
6. **선생님**이 마이페이지에서 수업 결과물과 거래명세서를 확인합니다.

각 단계를 그림으로 정리한 내용은 [전체 진행 흐름도](/reference/flow)에서 확인하실 수 있습니다.

## 설명서 읽는 방법

- **굵은 글씨**는 화면에 실제로 표시되는 버튼이나 메뉴 이름입니다.
- 색이 있는 안내 상자는 반드시 확인이 필요한 내용입니다.
- 찾으시는 내용이 있으면 오른쪽 위 **검색**에 버튼 이름을 그대로 입력해 보세요.
- 입력 항목의 글자 수나 필수 여부가 궁금하면 [입력 규칙 한눈에 보기](/reference/validation)를 확인해 주세요.
