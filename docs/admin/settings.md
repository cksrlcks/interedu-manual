# 7. 계정 관리

자주 사용하지는 않지만 알아 두면 좋은 메뉴입니다.

## 회원관리

왼쪽 메뉴에서 **계정관리 → 회원관리**를 누릅니다.
홈페이지에 가입한 회원 목록을 확인합니다.

## 관리자관리 {#admins}

왼쪽 메뉴에서 **계정관리 → 관리자관리**를 누릅니다.
관리자 계정을 추가합니다. 관리자는 회원가입 화면이 없으므로 이곳에서만 생성할 수 있습니다.

1. **등록**을 누릅니다.
2. 다음 항목을 입력합니다.

| 항목 | 조건 |
| --- | --- |
| **아이디** | 최대 20자 |
| **비밀번호** | 영문, 숫자, 특수문자(`!@#$%^&*`)를 각각 1자 이상 포함하여 8자 이상 |
| **이름** | 최대 20자 |
| **권한 코드** | 최대 8자 |

3. **등록**을 누릅니다.

::: danger 관리자 계정 관리
관리자는 모든 신청 정보와 개인정보를 확인할 수 있습니다.
담당자 변경이나 퇴사 시에는 계정을 정리해 주세요.
:::
