# 2. 강사 승인 관리

강사는 가입할 때와 정보를 수정할 때 모두 관리자 승인이 필요합니다.
두 경우 모두 **강사관리 → 강사신청 관리**에서 처리합니다.

::: danger 승인 전까지의 상태
신규 가입 요청은 승인 전까지 **강사가 로그인할 수 없습니다.**
수정 요청은 승인 전까지 **강사의 정보가 변경되지 않습니다.**
:::

## 요청 목록

왼쪽 메뉴에서 **강사관리 → 강사신청 관리**를 누릅니다.

| 항목 | 내용 |
| --- | --- |
| 번호 | 요청 번호 |
| 이름 · 아이디 | 신청한 강사 |
| 소속 | 단체명 |
| **구분** | **신규**(가입) 또는 **수정**(정보 변경) |
| **승인 상태** | 접수됨, 처리중, 처리완료, 요청취소, 요청거절 |
| 등록일 | 요청이 접수된 날짜 |
| 관리 | **상세** 버튼 |

![강사신청 관리 목록 화면](/images/admin/admin-03-tutor-requests.png)

## 요청 내용 확인

**상세**를 누르면 강사가 제출한 내용을 모두 확인할 수 있습니다.

- 기본 정보 : 아이디, 단체명, 주소, 주요 분야, 은행과 계좌
- 학력 목록
- 경력 목록
- 프로필 사진
- 첨부 파일 (자격증 사본 등)

::: tip 수정 요청의 경우
**수정** 구분인 요청에는 강사가 변경하려는 내용이 표시됩니다.
승인하면 이 내용이 실제 강사 정보로 반영됩니다.
:::

![강사신청 상세 화면](/images/admin/admin-04-tutor-request-detail.png)

## 승인 처리

오른쪽 **처리** 영역에서 진행합니다.

1. **승인 상태** 목록에서 값을 선택합니다.

| 선택 값 | 사용 시점 |
| --- | --- |
| **처리중** | 검토를 시작했음을 표시합니다. 아직 승인은 아닙니다. |
| **처리완료** | 승인 처리입니다. 가입 요청이면 로그인이 가능해지고, 수정 요청이면 정보가 반영됩니다. |

2. **변경 저장**을 누릅니다.
3. `승인 상태가 변경되었습니다.` 안내가 표시됩니다.

::: warning 처리완료가 승인입니다
별도의 승인 버튼은 없습니다. **승인 상태를 처리완료로 변경한 뒤 저장**하는 것이 승인 처리입니다.
:::

## 거절 처리

1. 오른쪽 **거절** 버튼을 누릅니다.
2. **거절 사유**를 입력합니다. 입력한 내용은 강사에게 표시됩니다.
3. **거절 확인**을 누릅니다.

거절 사유는 상세 화면 오른쪽에 기록되어 나중에도 확인할 수 있습니다.

::: tip 거절 사유는 구체적으로 작성해 주세요
재신청 시 무엇을 보완해야 하는지 알 수 있도록 구체적으로 작성하면 처리 과정이 줄어듭니다.
:::

## 처리 가능한 상태

**접수됨** 또는 **처리중** 상태에서만 처리와 거절 버튼이 표시됩니다.
이미 **처리완료**, **요청취소**, **요청거절**로 종료된 요청은 내용만 확인할 수 있습니다.

## 승인된 강사 확인

왼쪽 메뉴에서 **강사관리 → 인력풀 관리**를 누르면 승인이 완료된 강사를 확인할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 이름 · 아이디 | 강사 정보 |
| 주소 | 활동 지역 확인용 |
| **주요 분야** | 진행 가능한 수업 분야 |
| 출강 | 배정된 강의 수 |

**상세**를 누르면 학력, 경력, 첨부 파일까지 확인할 수 있습니다.

::: tip 강사 배정 전 확인
수강 신청에 강사를 배정하기 전에 이곳에서 주요 분야와 주소를 미리 확인해 두시면 배정이 수월합니다.
:::
