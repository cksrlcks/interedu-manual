# 6. 계정 정보와 비밀번호

왼쪽 메뉴 **계정 정보**에서 기본 정보를 확인하고 비밀번호를 변경합니다.

::: info 이미지 자리 · `tutor/tutor-11-account.png`
계정 정보 화면 (기본 정보와 비밀번호 변경 영역)
:::

## 기본 정보 확인

이름, 이메일, 전화번호, 아이디를 확인할 수 있습니다.
이 항목의 변경이 필요한 경우 인터에듀 담당자에게 문의해 주세요.

단체명, 주소, 주요 분야, 학력, 경력은 [강사 정보 수정](/tutor/profile)에서 수정 요청을 보냅니다.

## 비밀번호 변경

1. **현재 비밀번호**를 입력합니다.
2. **새 비밀번호**를 입력합니다. 영문, 숫자, 특수문자(`!@#$%^&*`)를 모두 포함하여 8자에서 20자 사이로 설정합니다.
3. **새 비밀번호 확인**에 동일하게 한 번 더 입력합니다.
4. 오른쪽 **저장**을 누릅니다.

`비밀번호가 변경되었습니다` 안내가 표시되면 완료입니다.

::: tip 현재 비밀번호를 모르는 경우
로그인이 되지 않는 상태라면 로그인 화면의 **비밀번호 찾기**를 이용해 주세요.
자세한 방법은 [비밀번호 찾기](/tutor/access#find-password)에 있습니다.
:::

## 일반 홈페이지로 이동

왼쪽 메뉴 아래쪽의 **사용자 페이지로** 버튼을 누르면
프로그램을 둘러볼 수 있는 일반 홈페이지로 이동합니다.
