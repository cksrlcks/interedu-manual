# 5. 강의 관리

수강 신청을 확정하면 강의가 자동으로 생성됩니다.
이 화면에서는 생성된 강의의 진행 상황과 강사가 등록한 결과물을 확인합니다.

왼쪽 메뉴에서 **신청관리 → 강의 관리**를 누릅니다.

::: tip 강의는 자동으로 생성됩니다
강의는 [신청 확정](/admin/applies#confirm) 시점에 자동으로 생성되므로 직접 만들 필요가 없습니다.
:::

## 강의 목록

| 항목 | 내용 |
| --- | --- |
| 번호 | 강의 번호 |
| 신청자 | 신청한 선생님 |
| 신청 정보 | 프로그램과 장소 요약 |
| **강의 일정** | 확정된 날짜와 시간 |
| **진행 상태** | 강의시작전, 강의중, 강의종료 |
| 등록일 | 생성된 날짜 |
| 관리 | **상세** |

::: info 이미지 자리 · `admin/admin-11-lectures.png`
강의 관리 목록 화면
:::

## 강의 상세

| 영역 | 내용 |
| --- | --- |
| **신청자 정보** | 이름, 이메일, 전화번호, 아이디 |
| **신청 정보** | 신청 번호, 프로그램, 학급수, 학급 상세, 총 인원, 신청 장소, 확정일자, 대표 선생님 연락처, 추가 문의 |
| **강사 정보** | 배정된 강사 |
| **활동 내역** | 반별로 강사가 입력한 참여인원, 활동 사진, 결과보고서 |

::: info 이미지 자리 · `admin/admin-12-lecture-detail.png`
강의 상세 화면 (활동 내역 영역이 보이도록 촬영)
:::

## 수업 후 확인하기 {#after-class}

수업 종료 후 **활동 내역** 영역에서 강사가 결과물을 등록했는지 확인합니다.

| 확인 항목 | 비어 있는 경우 |
| --- | --- |
| **참여인원** | 강사에게 입력을 요청합니다 |
| **활동 사진** | 강사에게 업로드를 요청합니다. 반당 최대 5장, PNG 또는 JPG 형식입니다 |
| **결과보고서** | 강사가 자동 생성하거나 직접 등록합니다 |

이 자료는 선생님의 마이페이지 **강의 정보** 탭에 그대로 표시됩니다.
선생님에게 표시되기 전에 내용을 한 번 확인해 주세요.

## 오른쪽 영역

| 항목 | 설명 |
| --- | --- |
| **강의 단계** | 강의시작전, 강의중, 강의종료 |
| **신청 상세** | 이 강의의 원래 수강 신청 건으로 이동합니다 |
| **강의 삭제** | 강의를 삭제합니다 |

::: danger 강의 삭제는 되돌릴 수 없습니다
`강의를 삭제하시겠습니까?` 확인 창이 표시됩니다.
강사가 등록한 사진과 보고서도 함께 확인할 수 없게 되므로, 잘못 생성된 강의가 아닌 경우 삭제하지 않는 것을 권장합니다.
:::
