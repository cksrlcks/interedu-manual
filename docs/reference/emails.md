# 자동으로 발송되는 메일

특정 작업을 진행하면 시스템이 자동으로 메일을 발송합니다.
발송 시점과 수신자는 다음과 같습니다.

| 메일 제목 | 발송 시점 | 수신자 |
| --- | --- | --- |
| `[인터에듀] 수강신청이 완료되었습니다` | 선생님이 수강 신청을 완료했을 때 | 신청한 선생님 |
| `[인터에듀] 수강신청이 취소되었습니다` | 선생님이 **접수취소**를 실행했을 때 | 신청한 선생님 |
| `[인터에듀] 수강이 확정되었습니다` | 관리자가 **신청 확정하기**를 실행했을 때 | 신청한 선생님 |
| `[인터에듀] 강의가 배정되었습니다` | 관리자가 **신청 확정하기**를 실행했을 때 | 배정된 강사 전원 |
| `[인터에듀] 문의에 답변이 작성되었습니다` | 관리자가 문의에 **답변 등록**을 했을 때 | 문의를 작성한 회원 |
| `[인터에듀] 비밀번호 재설정 안내` | **비밀번호 찾기**를 실행했을 때 | 본인 |

::: tip 메일이 도착하지 않는다는 문의를 받았을 때
1. 먼저 스팸메일함을 확인하도록 안내합니다.
2. 가입 시 입력한 이메일 주소가 정확한지 확인합니다.
   - 회원은 관리자 **회원관리**에서 확인합니다.
   - 강사는 관리자 **인력풀 관리**의 상세 화면에서 확인합니다.
3. 강사 메일은 배정된 강사에게만 발송됩니다. 배정되지 않은 강사에게는 발송되지 않습니다.
:::

::: warning 메일은 알림 수단입니다
메일이 도착하지 않아도 화면의 정보는 정상적으로 반영되어 있습니다.
진행 상황은 선생님의 마이페이지 또는 강사의 강의 관리 화면에서 확인하는 것이 정확합니다.
:::
