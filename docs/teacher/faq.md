# 선생님 자주 묻는 질문

궁금한 항목을 누르면 답변이 펼쳐집니다.

## 신청 전

::: details 회원가입 없이 신청할 수 있나요
프로그램을 둘러보는 것은 로그인 없이 가능하지만, 신청은 회원가입 후에 할 수 있습니다.

수강바구니, 관심 등록, 문의도 로그인이 필요합니다.
:::

::: details 프로그램 상세에 표시된 금액이 최종 금액인가요
아닙니다. 인원과 학급수에 따라 달라집니다.

정확한 금액은 신청 후 담당자가 발행하는 **견적서**로 확인해 주세요.
:::

::: details 여러 프로그램을 한 번에 신청할 수 있나요
가능합니다.

수강바구니에 담아 한 번에 신청하시거나, 신청서 안에서 **프로그램 추가하기**로 추가하실 수 있습니다.
:::

## 신청서 작성

::: details 희망 일정을 세 개 모두 입력해야 하나요
네, 1순위부터 3순위까지 모두 입력해 주세요.

강사 일정이 겹치면 1순위 날짜로 진행이 어려울 수 있습니다.
예비 일정까지 주셔야 담당자가 바로 일정을 확정할 수 있습니다.
:::

::: details 오늘 날짜로 신청할 수 있나요
선택할 수 없습니다. **내일 이후의 날짜**만 고를 수 있습니다.

급한 일정은 신청서를 제출하신 뒤 **1:1 대화**로 담당자에게 알려 주세요.
:::

::: details 2순위 날짜만 입력했는데 안내가 표시됩니다
날짜와 시간은 함께 입력해야 합니다.

두 항목을 모두 입력하시거나, 모두 비워 주세요.
:::

::: details 반마다 다른 프로그램을 지정할 수 있나요
가능합니다. **프로그램 배정**에서 반별로 다른 프로그램을 선택하시면 됩니다.

신청은 한 건으로 묶여서 처리됩니다.
:::

::: details 대표 선생님 연락처는 왜 필요한가요
수업 당일 배정된 강사가 연락할 번호입니다.

강사 화면에 그대로 표시되므로, 당일 연락이 가능한 번호를 입력해 주세요.
:::

## 신청 후

::: details 신청 후 언제 연락을 받을 수 있나요
영업일 기준 24시간 이내에 담당자가 연락드립니다.
:::

::: details 신청을 취소하고 싶습니다
수강확정 전이라면 신청 상세 오른쪽의 **접수취소**로 직접 취소하실 수 있습니다.

확정 이후에는 화면에서 취소할 수 없으므로 **1:1 대화**로 담당자에게 알려 주세요.
:::

::: details 강의 정보 탭이 비어 있습니다
수강확정 후에 내용이 표시됩니다. 아직 접수중 단계입니다.

진행 상황은 신청 상세 오른쪽의 **접수 상태**에서 확인하실 수 있습니다.
:::

::: details 견적서가 보이지 않습니다
담당자가 일정과 인원을 확정한 뒤 발행합니다.

필요하시면 **1:1 대화**로 요청해 주세요.
:::

::: details 거래명세서는 언제 받을 수 있나요
수업이 끝난 뒤 담당자가 실제 참여인원을 확인해 발행합니다.

발행되면 신청 상세의 **결제 정보** 탭 문서함에 표시되며, 누르면 내려받아집니다.
:::

::: details 어떤 강사가 방문하는지 미리 확인할 수 있나요
수강확정 후 신청 상세의 **강의 정보** 탭에서 이름, 연락처, 이메일을 확인하실 수 있습니다.

한 건에 여러 명이 배정될 수 있습니다.
:::

::: details 수업 사진은 언제 확인할 수 있나요
수업 종료 후 강사가 사진과 결과보고서를 등록하면 **강의 정보** 탭 아래 **학급별 강의 내역**에 표시됩니다.

등록까지 며칠이 소요될 수 있으며, 오래 지연되는 경우 **1:1 대화**로 문의해 주세요.
:::

::: details 인원이 바뀌었습니다
신청 상세의 **1:1 대화**로 담당자에게 알려 주세요.

견적서 금액에 영향을 주므로 확정 전에 알려 주시면 좋습니다.
:::
