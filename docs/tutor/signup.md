# 2. 강사 회원가입

강사 가입은 세 단계로 진행되며, 가입 후 **관리자 승인이 완료되어야 로그인할 수 있습니다.**

접속 주소는 `https://interedu.ai.kr/tutor/sign-up` 입니다.
강사 로그인 화면에서 **회원가입**을 눌러 이동하셔도 됩니다.

![회원가입 3단계 표시](/images/tutor/tutor-03-signup-steps.png)

## 1단계. 이용약관 동의

약관 내용을 확인하고 동의 항목에 체크합니다.
필수 항목에 모두 동의해야 다음 단계로 진행됩니다.

## 2단계. 기본 정보 입력

로그인과 연락에 사용되는 정보입니다. 별표(\*)가 표시된 항목은 모두 필수입니다.

| 항목 | 입력 방법 |
| --- | --- |
| **이름** | 실명을 입력합니다. |
| **아이디** | **8자 이상**으로 입력한 뒤 **중복확인** 버튼을 누릅니다. 글자 수 상한은 없습니다. |
| **비밀번호** | 영문, 숫자, 특수문자(`!@#$%^&*`)를 모두 포함하여 **8~20자**로 입력합니다. |
| **비밀번호 확인** | 위와 동일하게 한 번 더 입력합니다. |
| **이메일** | 입력한 뒤 **중복확인** 버튼을 누릅니다. 안내 메일이 이 주소로 발송됩니다. |
| **연락처** | `010-1234-5678` 형식으로 입력합니다. |
| **주소** | **주소 검색** 버튼을 눌러 우편번호로 검색합니다. |
| **상세 주소** | 동, 호수 등 나머지 주소를 직접 입력합니다. |

::: warning 중복확인을 완료해야 다음 단계로 진행됩니다
아이디와 이메일은 **중복확인**을 눌러 사용 가능 안내를 받아야 **다음** 버튼이 활성화됩니다.
중복확인 후 아이디나 이메일을 수정하면 확인이 해제되므로 다시 눌러 주세요.
:::

![2단계 기본 정보 입력 화면](/images/tutor/tutor-04-signup-basic.png)

## 3단계. 강사 정보 입력

수업 배정과 정산에 사용되는 정보입니다.

| 항목 | 입력 방법 |
| --- | --- |
| **단체명** (필수) | 공방, 기관, 팀 이름을 입력합니다. 개인의 경우 본인 이름이나 활동명을 입력합니다. |
| **주요 분야** (필수) | 해당하는 분야를 여러 개 선택할 수 있습니다. 관리자가 강사를 배정할 때 참고하는 항목입니다. |
| 은행 · 계좌 번호 | 선택 항목입니다. 가입 후 정보 수정에서 추가하셔도 됩니다. |

::: tip 학력과 경력은 가입 단계에서 비워 두셔도 됩니다
등록하지 않아도 가입은 진행됩니다. 가입 후 **강사 정보** 화면에서 추가하실 수 있습니다.
다만 **한 줄을 추가했다면 그 줄의 칸을 모두 채워야** 다음으로 넘어갑니다.
:::

### 학력 입력

**추가** 버튼을 누르면 입력란이 한 줄 생성됩니다. 여러 개를 등록할 수 있습니다.

| 항목 | 입력 방법 |
| --- | --- |
| 학력 구분 · 학력 상태 | 목록에서 선택합니다. 필수 |
| 학교명 · 전공명 | 직접 입력합니다. 필수 |
| 부전공명 | 해당 사항이 없으면 비워 둡니다. 선택 |
| 졸업일자 | 달력에서 선택합니다. 필수 |
| 정렬 순서 | 목록에 표시할 순서입니다. **1 이상**의 숫자를 입력합니다 |

잘못 추가한 항목은 해당 줄의 **삭제** 버튼으로 제거합니다.

### 경력 입력

학력과 동일한 방식입니다. **추가** 버튼을 누르고 아래 항목을 입력합니다.

| 항목 | 입력 방법 |
| --- | --- |
| 경력 구분 | 목록에서 선택합니다. 필수 |
| 주관 업체 · 경력 일자 · 업무 내용 | 직접 입력합니다. 필수 |
| 정렬 순서 | **1 이상**의 숫자를 입력합니다 |

![3단계 강사 정보 입력 화면](/images/tutor/tutor-05-signup-tutor-info.png)

마지막으로 **가입하기**를 누르면 `강사 신청이 완료되었습니다. 승인 후 로그인 가능합니다.` 안내가 표시되고 로그인 화면으로 이동합니다.

## 승인 절차 {#approval}

가입 신청을 하면 관리자에게 강사 신청 건이 접수됩니다.

| 승인 상태 | 의미 |
| --- | --- |
| **접수됨** | 신청이 접수되었으며 아직 검토 전입니다. |
| **처리중** | 관리자가 검토하고 있습니다. |
| **처리완료** | 승인이 완료되었습니다. 이제 로그인할 수 있습니다. |
| **요청거절** | 승인되지 않았습니다. 거절 사유가 함께 기록됩니다. |
| **요청취소** | 신청자가 직접 취소한 경우입니다. |

::: danger 승인 전에는 로그인할 수 없습니다
승인 상태가 **처리완료**로 변경되기 전에는 아이디와 비밀번호가 일치해도 로그인되지 않습니다.
승인이 지연되는 경우 인터에듀 담당자에게 문의해 주세요.
:::
