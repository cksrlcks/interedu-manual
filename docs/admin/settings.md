# 7. 회원 · 시스템 설정

자주 사용하지는 않지만 알아 두면 좋은 메뉴입니다.

## 계정관리

### 회원관리

왼쪽 메뉴에서 **계정관리 → 회원관리**를 누릅니다.
홈페이지에 가입한 회원 목록을 확인합니다.

### 관리자관리 {#admins}

왼쪽 메뉴에서 **계정관리 → 관리자관리**를 누릅니다.
관리자 계정을 추가합니다. 관리자는 회원가입 화면이 없으므로 이곳에서만 생성할 수 있습니다.

1. **등록**을 누릅니다.
2. 다음 항목을 입력합니다.

| 항목 | 조건 |
| --- | --- |
| **아이디** | 최대 20자 |
| **비밀번호** | 영문, 숫자, 특수문자(`!@#$%^&*`)를 각각 1자 이상 포함하여 8자 이상 |
| **이름** | 최대 20자 |
| **권한 코드** | 최대 8자 |

3. **등록**을 누릅니다.

::: danger 관리자 계정 관리
관리자는 모든 신청 정보와 개인정보를 확인할 수 있습니다.
담당자 변경이나 퇴사 시에는 계정을 정리해 주세요.
:::

## 시스템

### 카테고리 관리 {#categories}

왼쪽 메뉴에서 **시스템 → 카테고리 관리**를 누릅니다.
프로그램을 분류하는 카테고리를 관리하며, 상위와 하위 구조로 되어 있습니다.

- 상위 카테고리를 선택한 뒤 하위 카테고리를 추가합니다.
- 이곳에서 만든 분류가 [프로그램 등록](/admin/programs#basic-info) 화면의 선택 목록에 표시됩니다.

| 항목 | 규칙 |
| --- | --- |
| 상위 · 하위 카테고리 코드 | **정확히 7자리** |
| 카테고리명 | 필수. 최대 **20자** |
| 사용여부 | 사용하지 않음으로 두면 홈페이지 선택 목록에 표시되지 않습니다 |
| 정렬 순서 | **0 이상**의 정수. 작은 숫자가 먼저 표시됩니다 |

::: warning 사용 중인 카테고리 삭제
해당 분류를 사용하던 프로그램의 분류가 비게 됩니다.
프로그램을 먼저 다른 분류로 옮긴 뒤 삭제해 주세요.
:::

### 공통코드 관리

왼쪽 메뉴에서 **시스템 → 공통코드 관리**를 누릅니다.
화면 곳곳의 선택 목록에 사용되는 값을 관리합니다.
강사 가입 화면의 주요 분야, 학력 구분, 경력 구분 등이 이곳의 값을 사용합니다.

::: danger 값을 변경하기 전에 확인해 주세요
공통코드는 여러 화면에서 동시에 사용됩니다.
삭제하면 해당 값을 사용하던 기존 데이터가 정상적으로 표시되지 않을 수 있습니다.
새로 추가하는 것은 문제가 없으나, 수정과 삭제는 개발 담당자와 상의한 뒤 진행해 주세요.
:::

### 게시판 관리

왼쪽 메뉴에서 **시스템 → 게시판 관리**를 누릅니다.
공지사항, FAQ, 문의 같은 게시판 자체를 생성하고 설정합니다.

| 항목 | 설명 |
| --- | --- |
| **게시판 코드** | 최대 7자입니다. 생성 후에는 변경하지 않는 것을 권장합니다 |
| **게시판명** | 화면에 표시되는 이름입니다 |
| **게시판 유형** | 공지사항, 자유게시판, FAQ, Q&A, 썸네일 중에서 선택합니다. 유형에 따라 화면 구성이 달라집니다 |
| **첨부파일 최대 개수** | 글당 등록할 수 있는 파일 수입니다 |
| **허용 파일 확장자** | 예) `pdf,hwp,jpg,png` |
| **사용여부 · 댓글 허용 · 답변 허용 · 비밀글 허용** | 사용 여부를 지정합니다 |

::: warning 운영 중인 게시판은 변경에 주의해 주세요
현재 운영 중인 게시판은 홈페이지 화면과 연결되어 있습니다.

| 게시판 | 사용되는 위치 |
| --- | --- |
| 공지사항 | 홈 화면 공지, 상단 메뉴 공지사항 |
| FAQ | 상단 메뉴 자주 묻는 질문 |
| 문의 | 선생님 마이페이지 나의 문의 |

코드나 유형을 변경하면 홈페이지가 정상적으로 표시되지 않을 수 있습니다.
:::
