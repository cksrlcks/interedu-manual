# 6. 공지사항 · FAQ · 문의관리

세 메뉴 모두 게시판이므로 화면 구조가 거의 동일합니다.
왼쪽 메뉴 **운영관리** 아래에 있습니다.

| 메뉴 | 홈페이지에 표시되는 위치 |
| --- | --- |
| **공지사항** | 홈 화면 공지 영역, 상단 메뉴 공지사항 |
| **FAQ** | 상단 메뉴 자주 묻는 질문, 홈 화면 미리보기 |
| **문의관리** | 선생님의 마이페이지 나의 문의 |

## 공지사항

### 글 작성

1. **운영관리 → 공지사항**으로 이동합니다.
2. 오른쪽 위의 **등록**을 누릅니다.
3. **제목**과 **내용**을 입력합니다. 제목은 최대 200자입니다.
4. 오른쪽 **설정**에서 옵션을 지정합니다.

| 옵션 | 설명 |
| --- | --- |
| **공지 여부** | 사용 시 목록 상단에 고정됩니다 |
| **숨김 여부** | 사용 시 홈페이지에 표시되지 않습니다 |

5. 오른쪽 **저장** 영역의 **등록**을 누릅니다.

### 수정과 삭제

목록에서 해당 글의 **수정** 또는 **삭제**를 누릅니다. 삭제 시 확인 창이 표시됩니다.

::: tip 미리 작성한 뒤 나중에 공개하기
**숨김 여부**를 사용한 상태로 저장해 두었다가, 공개 시점에 해제하시면 됩니다.
:::

::: info 이미지 자리 · `admin/admin-13-notice.png`
공지사항 작성 화면
:::

## FAQ

### 글 작성

1. **운영관리 → FAQ**로 이동합니다.
2. **등록**을 누릅니다.
3. **제목**에 질문을, **내용**에 답변을 입력합니다.
4. 오른쪽 **설정**에서 옵션을 지정합니다.

| 옵션 | 설명 |
| --- | --- |
| **FAQ 구분** | 공통, 신청자, 강사, 계약, S2B이용, 정산 |
| **메인 노출** | 사용 시 홈 화면 FAQ 미리보기에 표시됩니다 |
| **숨김 여부** | 사용 시 홈페이지에 표시되지 않습니다 |

5. **등록**을 누릅니다.

::: tip 구분 선택 기준
선생님은 주로 **신청자** 분류를, 강사는 **강사** 분류를 확인합니다.
양쪽 모두에 해당하는 내용은 **공통**으로 지정해 주세요.
:::

::: info 이미지 자리 · `admin/admin-14-faq.png`
FAQ 작성 화면 (오른쪽 FAQ 구분 설정이 보이도록 촬영)
:::

## 문의관리

선생님이 **나의 문의**에 남긴 글에 답변합니다.

### 목록

| 항목 | 내용 |
| --- | --- |
| 번호 | 글 번호 |
| 제목 | 문의 제목 |
| 작성자 | 문의한 회원 |
| **답변** | 답변 등록 여부 |
| 등록일 | 문의한 날짜 |
| 관리 | **답변하기** 또는 **답변수정**, **삭제** |

::: tip 처리할 문의 확인
목록에서 **답변** 항목이 비어 있는 글이 아직 처리되지 않은 문의입니다.
:::

### 답변 등록

1. 해당 문의의 **답변하기**를 누릅니다.
2. 위쪽 **질문** 영역에서 문의 내용을 확인합니다.
3. 아래 **답변** 영역의 **답변 내용**에 답변을 입력합니다.
4. 오른쪽 **저장** 영역의 **답변 등록**을 누릅니다.

답변을 등록하면 문의한 회원에게 `[인터에듀] 문의에 답변이 작성되었습니다` 메일이 자동으로 발송됩니다.

### 답변 수정

이미 답변한 글은 **답변수정**으로 이동하여 내용을 변경한 뒤 **답변 수정**을 누릅니다.

::: info 이미지 자리 · `admin/admin-15-inquiry-answer.png`
문의 답변 화면 (위쪽 질문과 아래쪽 답변)
:::

## 신청 건에 대한 문의는 별도 화면입니다

선생님이 신청 상세의 **1:1 대화**에 남긴 메시지는 문의관리에 표시되지 않습니다.
**신청관리 → 수강 신청 관리**에서 해당 신청의 **1:1 대화**를 확인해 주세요.
자세한 내용은 [수강 신청 관리](/admin/applies#chat)에 있습니다.
