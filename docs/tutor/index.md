# 강사 설명서 시작하기

이 설명서는 학교나 기관으로 수업을 하러 나가시는 분을 위한 안내서입니다.
개인 강사, 공방, 대학, 기관 등 형태와 관계없이 모두 **강사**로 가입하여 같은 화면을 사용합니다.

## 강사가 하는 일

| 순서 | 하는 일 | 설명서 |
| --- | --- | --- |
| 1 | 강사 전용 주소로 접속합니다 | [관리시스템 접속하기](/tutor/access) |
| 2 | 회원가입 후 관리자 승인을 기다립니다 | [강사 회원가입](/tutor/signup) |
| 3 | 프로필과 학력, 경력을 수정 요청합니다 | [강사 정보 수정](/tutor/profile) |
| 4 | 배정된 강의의 일정과 준비 서류를 확인합니다 | [강의 관리](/tutor/lectures) |
| 5 | 수업 후 사진을 등록하고 결과보고서를 만듭니다 | [강의 후 정리](/tutor/after-class) |

## 화면 구성

로그인하면 왼쪽에 다음 메뉴가 항상 표시됩니다.

| 메뉴 | 할 수 있는 일 |
| --- | --- |
| **대시보드** | 프로필 요약과 이번 달 강의 일정을 달력으로 확인합니다 |
| **강사 정보** | 단체명, 주소, 주요 분야, 학력, 경력, 프로필 사진을 수정 요청합니다 |
| **강의 관리** | 배정된 강의를 확인하고 준비 서류를 받으며, 수업 결과를 등록합니다 |
| **계정 정보** | 기본 정보를 확인하고 비밀번호를 변경합니다 |

메뉴 아래쪽의 **사용자 페이지로** 버튼을 누르면 일반 홈페이지로 이동합니다.
