# 상태값 한눈에 보기

화면에 표시되는 상태 이름을 정리했습니다.

## 수강 신청 · 신청 상태

신청 자체가 유효한지를 나타냅니다.

| 상태 | 의미 | 변경 주체 |
| --- | --- | --- |
| **신청 완료** | 정상적으로 접수된 상태입니다 | 선생님이 신청할 때 |
| **신청 취소** | 선생님이 직접 취소한 상태입니다 | 선생님 (수강확정 전까지) |
| **신청 거절** | 관리자가 진행 불가로 거절한 상태입니다 | 관리자 |

## 수강 신청 · 진행 상태

처리가 어디까지 진행되었는지를 나타냅니다.

| 상태 | 의미 | 함께 일어나는 일 |
| --- | --- | --- |
| **접수 중** | 확인과 조율이 진행 중입니다 | 선생님은 아직 강사 정보를 확인할 수 없습니다 |
| **수강 확정** | 일정, 강사, 견적이 확정되었습니다 | 강의가 자동 생성되고 안내 메일이 발송됩니다 |

## 강의 상태

| 상태 | 의미 |
| --- | --- |
| **강의시작전** | 아직 수업 날짜가 되지 않았습니다 |
| **강의중** | 수업 진행 기간입니다 |
| **강의종료** | 수업이 종료되었습니다 |

## 강사 승인 상태

강사 가입 요청과 정보 수정 요청 모두 동일한 값을 사용합니다.

| 상태 | 의미 | 가능한 작업 |
| --- | --- | --- |
| **접수됨** | 요청이 접수되었습니다 | 강사는 취소, 관리자는 처리 가능 |
| **처리중** | 관리자가 검토 중입니다 | 강사는 취소, 관리자는 처리 가능 |
| **처리완료** | 승인이 완료되었습니다 | — |
| **요청취소** | 강사가 직접 취소했습니다 | — |
| **요청거절** | 관리자가 거절했으며 사유가 기록됩니다 | — |

## 강사 요청 구분

| 구분 | 의미 | 승인 시 결과 |
| --- | --- | --- |
| **신규** | 강사 가입 신청입니다 | 강사가 로그인할 수 있게 됩니다 |
| **수정** | 강사 정보 변경 요청입니다 | 변경하려던 내용이 실제 정보로 반영됩니다 |

## 문서 종류

### 수강 신청에 등록되는 문서

| 종류 | 생성 방법 | 삭제 |
| --- | --- | --- |
| **견적서** | 관리자가 견적서를 생성하면 자동으로 등록됩니다 | 불가 |
| **계약서** | 관리자가 직접 등록합니다 | 가능 |
| **거래명세서** | 수업 진행 후 자동으로 등록됩니다 | 불가 |
| **기타** | 관리자가 직접 등록합니다 | 가능 |

### 강의에 등록되는 문서

| 종류 | 생성 방법 |
| --- | --- |
| **운영확인서** | 수강 확정 시 자동으로 준비되며 강사가 내려받습니다 |
| **강사카드** | 강사가 **강사카드 생성**을 눌러 생성합니다 |
| **결과사진(활동 사진)** | 강사가 업로드합니다. PNG 또는 JPG, 반당 최대 5장입니다 |
| **결과보고서(활동보고서)** | 강사가 자동 생성하거나 PDF로 직접 등록합니다 |
| **기타** | 강사와 관리자가 문서함에 등록합니다 |
