# 1. 관리시스템 접속하기

강사가 사용하는 화면은 일반 홈페이지와 **주소가 다릅니다.**
아래 주소를 즐겨찾기에 등록해 두시면 편리합니다.

## 접속 주소

| 화면 | 주소 |
| --- | --- |
| 강사 로그인 | **`https://interedu.ai.kr/tutor/sign-in`** |
| 강사 회원가입 | `https://interedu.ai.kr/tutor/sign-up` |

::: warning 일반 홈페이지 로그인과 구분해 주세요
홈페이지(`interedu.ai.kr`) 첫 화면의 로그인은 수업을 신청하는 선생님을 위한 것입니다.
강사는 주소 끝에 `/tutor`가 붙은 화면에서 로그인해 주세요.
:::

## 로그인

1. 위 주소로 접속합니다.
2. **아이디**와 **비밀번호**를 입력합니다.
3. **로그인** 버튼을 누릅니다.

로그인에 성공하면 **대시보드** 화면으로 이동합니다.

![강사 로그인 화면](/images/tutor/tutor-02-signin.png)

::: danger 로그인이 되지 않는 경우
가입 직후라면 아직 관리자 승인이 완료되지 않은 상태일 수 있습니다.
승인이 완료되어야 로그인할 수 있습니다. 자세한 내용은 [승인 절차](/tutor/signup#approval)를 확인해 주세요.
:::

## 아이디 찾기

로그인 화면 아래의 **아이디 찾기**를 누릅니다.

1. 가입 시 입력한 **이름**을 입력합니다.
2. 가입 시 입력한 **연락처**를 `010-1234-5678` 형식으로 입력합니다.
3. **아이디 찾기** 버튼을 누르면 화면에 아이디가 표시됩니다.

## 비밀번호 찾기 {#find-password}

로그인 화면 아래의 **비밀번호 찾기**를 누릅니다.

1. **아이디**를 입력합니다.
2. 가입 시 입력한 **이메일**을 입력합니다.
3. **재설정 메일 발송** 버튼을 누릅니다.
4. 메일함에서 `[인터에듀] 비밀번호 재설정 안내` 메일을 열고, 안내된 링크에서 새 비밀번호를 설정합니다.

::: tip 메일이 도착하지 않는 경우
먼저 스팸메일함을 확인해 주세요. 그래도 없다면 가입 시 입력한 이메일 주소가 맞는지 확인이 필요합니다.
:::

## 로그아웃

왼쪽 메뉴 위쪽의 로그아웃 아이콘을 누르면 로그아웃됩니다.
여러 사람이 함께 사용하는 컴퓨터에서는 사용 후 반드시 로그아웃해 주세요.
