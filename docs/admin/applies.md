# 4. 수강 신청 관리와 강사 배정

관리자 업무의 핵심 화면입니다.
접수된 신청을 확인하고 일정을 확정한 뒤, 강사를 배정하고 견적서를 발행하여 신청을 확정합니다.
수업이 끝난 뒤에는 같은 화면에서 거래명세서를 발행합니다.

왼쪽 메뉴에서 **신청관리 → 수강 신청 관리**를 누릅니다.

## 신청 목록

| 항목 | 내용 |
| --- | --- |
| 번호 | 신청 번호 |
| 신청 정보 | 프로그램과 일정 요약 |
| 신청자 | 신청한 선생님 |
| **신청 상태** | 신청 완료, 신청 취소, 신청 거절 |
| **진행 상태** | 접수 중, 수강 확정 |
| 신청일 | 접수된 날짜 |
| 관리 | **상세** |

::: tip 두 가지 상태의 차이
**신청 상태**는 신청 자체가 유효한지를 나타내며, 취소와 거절 여부를 표시합니다.
**진행 상태**는 처리가 어디까지 진행되었는지를 나타냅니다.
:::

![수강 신청 관리 목록 화면](/images/admin/admin-07-applies.png)

## 신청 상세 화면

**상세**를 누르면 다음 순서로 구성된 화면이 표시됩니다.

1. **신청 정보** — 선생님이 제출한 내용
2. **일정 확정 및 문서 생성** — 실제 처리를 진행하는 영역
3. **문서함** — 신청 건 문서 관리
4. **1:1 대화** — 신청자와의 메시지
5. 오른쪽 **진행 단계**와 **접수** 영역

![신청 상세 화면](/images/admin/admin-08-apply-detail.png)

## 일정 확정 및 문서 생성

이 영역은 1번부터 4번까지 순서대로 진행합니다.
1번부터 3번까지는 신청을 확정하기 전에 진행하고, 4번 거래명세서는 수업이 끝난 뒤에 진행합니다.

### 1. 일정 선택

선생님이 제출한 1순위, 2순위, 3순위 희망 일정이 카드로 표시됩니다.
진행할 일정 카드를 누르면 선택 표시가 나타납니다.

- 선생님이 2순위와 3순위를 입력하지 않은 경우 `희망 일정 없음`으로 표시됩니다.
- 여기서 선택한 일정이 확정일자가 되어 강사와 선생님에게 표시됩니다.

::: warning 일정을 선택해야 확정할 수 있습니다
일정을 선택하지 않고 **신청 확정하기**를 누르면 `확정할 일정을 먼저 선택해주세요.` 안내가 표시됩니다.
:::

### 2. 강사 배정

이 신청을 담당할 강사를 지정합니다.

**강사 추가**

1. **강사 추가** 버튼을 누릅니다.
2. 강사 목록 창에서 배정할 강사를 선택합니다. 여러 명을 선택할 수 있습니다.
3. **배정**을 누릅니다.
4. `해당 강사가 배치되었습니다.` 안내가 표시되고 목록에 이름, 연락처, 이메일이 나타납니다.

**강사 제외**

1. 해당 강사 줄 오른쪽의 제외 아이콘을 누릅니다.
2. `강사 배정을 취소하시겠습니까?` 확인 창에서 진행합니다.
3. 배정이 취소되며, 이후 다시 추가할 수 있습니다.

::: tip 배정하면 바로 확정됩니다
강사에게 수락 여부를 확인하는 단계는 없습니다.
관리자가 배정하면 배정이 완료되어 강사 화면에 강의가 표시되므로, 사전에 강사와 일정을 조율한 뒤 배정해 주세요.
:::

::: tip 한 건에 여러 명을 배정할 수 있습니다
반이 많거나 인원이 많은 수업은 강사를 여러 명 배정하시면 됩니다.
배정된 강사 모두에게 같은 강의가 표시되며, 선생님 화면에도 모두 표시됩니다.
:::

![강사 배정 영역과 강사 선택 창](/images/admin/admin-09-assign-tutor.png)

### 3. 견적서

**견적서 생성**을 누르면 견적서 작성 창이 표시됩니다.

| 항목 | 설명 |
| --- | --- |
| **발행일** | 달력에서 선택합니다. 오늘 날짜가 기본값입니다. 필수 |
| **신청인** | 신청한 선생님 이름이 자동으로 입력됩니다 |
| **품목** | 품명, 단가, 수량을 줄 단위로 입력합니다. **1개 이상 10개 이하** |
| **품명** | 필수. 비어 있으면 저장되지 않습니다 |
| **단가** | **0 이상**의 숫자 |
| **수량** | **1 이상**의 숫자 |

- 창이 열릴 때 신청한 프로그램의 강사비와 재료비, 인원을 기준으로 품목이 자동으로 채워집니다. 필요한 부분만 수정하시면 됩니다.
- **행 추가**로 품목을 추가하고, 줄 오른쪽 아이콘으로 삭제합니다.
- 금액은 단가와 수량으로 자동 계산되며, 총액도 자동으로 합산됩니다.
- **견적서 저장**을 누르면 목록에 추가됩니다.

저장하면 견적서 파일이 자동으로 만들어집니다. 만들어지는 동안에는 `문서 생성 중...` 이 표시되고, 잠시 후 오른쪽 다운로드 아이콘으로 바뀝니다.

::: warning 파일은 가장 최근 견적서 한 건만 남습니다
견적서를 다시 생성하면 이전 파일이 새 파일로 덮어써집니다.
이전에 생성한 견적서는 목록에 취소선으로 표시되며 내려받을 수 없습니다.
화면에서 삭제할 수는 없으므로, 내용이 틀린 경우 새로 생성해 주세요.
:::

![견적서 작성 창](/images/admin/admin-10-estimate.png)

### 4. 거래명세서 {#trade-statement}

수업이 끝난 뒤 **실제 참여인원**을 기준으로 발행하는 정산 문서입니다.
**거래명세서 생성**을 누르면 작성 창이 표시됩니다.

::: warning 강의가 생성된 뒤에 작성할 수 있습니다
신청이 확정되기 전에는 **거래명세서 생성** 버튼이 눌리지 않으며, 옆에 `강의가 생성된 뒤에 작성할 수 있습니다.` 안내가 표시됩니다.
:::

작성 창 위쪽에 **학급별 참여 인원** 표가 함께 표시됩니다.

| 항목 | 설명 |
| --- | --- |
| 학급 · 프로그램 | 선생님이 신청서에 입력한 학급 정보 |
| **예정** | 신청 시 적은 인원 |
| **참여** | 강사가 수업 후 입력한 실제 인원. 입력 전에는 `미입력` |

- 품목의 재료비 수량은 **참여** 인원을 기준으로 자동 계산됩니다.
- 강사가 아직 입력하지 않은 학급은 **예정** 인원으로 계산됩니다. 강사에게 입력을 요청한 뒤 생성하시는 것을 권장합니다.

입력 항목은 견적서와 같습니다.

| 항목 | 설명 |
| --- | --- |
| **거래일자** | 달력에서 선택합니다. 오늘 날짜가 기본값입니다. 필수 |
| **신청인** | 신청한 선생님 이름이 자동으로 입력됩니다 |
| **품목** | 품명, 단가, 수량을 줄 단위로 입력합니다. **1개 이상 10개 이하** |

- 창이 열릴 때 프로그램의 강사비와 재료비, 참여인원을 기준으로 품목이 자동으로 채워집니다.
- **행 추가**로 품목을 추가하고, 줄 오른쪽 아이콘으로 삭제합니다.
- 합계 금액은 부가세가 포함된 금액입니다.
- **거래명세서 저장**을 누르면 목록에 추가되고 거래명세서 파일이 자동으로 만들어집니다.

만들어진 파일은 아래 **문서함**과 선생님의 마이페이지 **결제 정보** 탭에 함께 표시됩니다.

::: tip 수정이 필요하면 다시 생성합니다
거래명세서는 화면에서 수정하거나 삭제할 수 없습니다.
금액이 틀린 경우 새로 생성하시면 마지막에 생성한 내용이 최종본이 되며, 이전 건은 취소선으로 표시됩니다.
:::

## 신청 확정 {#confirm}

1번부터 3번까지 완료되었다면 오른쪽 **접수** 영역에서 마무리합니다.

1. **신청 확정하기**를 누릅니다.
2. 확인 창의 안내를 확인하고 진행합니다.

### 확정 시 함께 처리되는 내용

| 처리 내용 | 반영되는 위치 |
| --- | --- |
| 진행 상태가 **수강확정**으로 변경 | 관리자와 선생님 화면 |
| 선택한 일정이 확정일자로 저장 | 강사와 선생님 화면 |
| 강의 자동 생성 | 관리자 **강의 관리**, 강사 **강의 관리** |
| 운영확인서 준비 | 강사 화면의 **강사 준비물** |
| 신청자에게 메일 발송 | `[인터에듀] 수강이 확정되었습니다` |
| 배정된 강사에게 메일 발송 | `[인터에듀] 강의가 배정되었습니다` |
| 선생님 화면의 **강의 정보** 탭 활성화 | 강사 이름과 연락처가 표시됨 |

::: danger 확정 전 확인 사항
확정 전에 일정 선택, 강사 배정, 견적서 생성이 모두 완료되었는지 확인해 주세요.
확정 후에는 화면에서 되돌릴 수 없으며, 되돌려야 할 경우 개발 담당자에게 문의가 필요합니다.
:::

## 신청 거절

진행이 불가능한 신청은 **신청 거절하기**를 누릅니다.
`거절 후에는 되돌릴 수 없습니다.` 확인 창에서 진행합니다.

## 문서함

신청 건에 포함되는 서류를 관리합니다. **파일 업로드**로 등록하며 종류를 선택합니다.

| 종류 | 설명 |
| --- | --- |
| **견적서** | 견적서 생성 시 자동으로 등록됩니다 |
| **거래명세서** | [거래명세서 생성](#trade-statement) 시 자동으로 등록됩니다 |
| **기타** | 그 밖의 파일 |

등록한 파일은 선생님의 마이페이지 **결제 정보** 탭에 그대로 표시됩니다.

::: warning 견적서와 거래명세서는 삭제할 수 없습니다
자동으로 생성되는 문서이므로 삭제 버튼이 표시되지 않습니다.
직접 등록한 기타 파일만 삭제할 수 있습니다.
:::

## 1:1 대화 {#chat}

신청자와 주고받는 메시지입니다. 이곳에 작성한 내용은 선생님의 **1:1 대화** 탭에 바로 표시됩니다.

::: tip 조율 결과를 기록해 주세요
전화로 조율하신 경우에도 결과를 한 줄 남겨 두면 이후 확인이 정확합니다.
:::
