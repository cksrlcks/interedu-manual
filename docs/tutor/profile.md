# 3. 강사 정보 수정

왼쪽 메뉴 **강사 정보**에서 프로필을 수정합니다.

::: danger 저장 즉시 반영되지 않습니다
**저장하기**를 눌러도 정보가 바로 변경되지 않습니다.
관리자에게 수정 요청이 접수되고, **관리자가 승인해야 실제로 반영**됩니다.
:::

::: info 이미지 자리 · `tutor/tutor-06-profile.png`
강사 정보 화면 전체 (오른쪽 수정 요청 내역이 함께 보이도록 촬영)
:::

## 수정할 수 있는 항목

| 구분 | 항목 |
| --- | --- |
| 프로필 정보 | 단체명, 주소, 상세 주소, 주요 분야, 은행, 계좌 번호 |
| 학력 | 여러 개 추가, 수정, 삭제 |
| 경력 | 여러 개 추가, 수정, 삭제 |
| 프로필 사진 | 1장. 강사카드와 선생님 화면에 표시되는 사진입니다 |
| 첨부 파일 | 자격증 사본 등 |

이름, 아이디, 이메일, 연락처는 이 화면에서 변경하지 않습니다.
비밀번호 변경은 [계정 정보](/tutor/account)에서 진행합니다.

## 수정 순서

1. 왼쪽 메뉴에서 **강사 정보**를 누릅니다.
2. 변경할 항목의 내용을 수정합니다.
   - 학력과 경력은 **추가** 버튼으로 줄을 늘리고, 필요 없는 줄은 **삭제**로 제거합니다.
   - 사진과 파일은 해당 영역에서 파일을 선택해 업로드합니다.
3. 오른쪽 **저장** 영역의 **저장하기** 버튼을 누릅니다.
4. `수정 요청이 접수되었습니다.` 안내가 표시됩니다.

## 요청 처리 상황 확인

같은 화면 오른쪽 아래의 **수정 요청 내역**에 지금까지 보낸 요청이 기록됩니다.
각 줄에는 구분(신규 또는 수정), 상태, 요청한 날짜가 표시됩니다.

| 상태 | 의미 | 가능한 작업 |
| --- | --- | --- |
| **접수됨** | 요청이 접수되었습니다 | 취소 가능 |
| **처리중** | 관리자가 검토하고 있습니다 | 취소 가능 |
| **처리완료** | 승인되어 정보가 반영되었습니다 | — |
| **요청거절** | 승인되지 않았습니다 | — |
| **요청취소** | 직접 취소한 요청입니다 | — |

### 요청 취소

**접수됨** 또는 **처리중** 상태에서는 오른쪽 **취소** 버튼을 누를 수 있습니다.
확인 창에서 한 번 더 누르면 요청이 취소되고, 정보는 기존 상태로 유지됩니다.

::: tip 수정 요청은 여러 번 보낼 수 있습니다
급하게 변경이 필요한 내용이 있다면 요청을 보낸 뒤 인터에듀 담당자에게 알려 주시면 더 빠르게 처리됩니다.
:::
