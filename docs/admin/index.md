# 관리자 설명서 시작하기

관리자는 인터에듀 운영 전반을 담당합니다.
강사를 승인하고, 프로그램을 등록하며, 접수된 수강 신청을 확정하면서 강사를 배정합니다.

## 관리자가 하는 일

| 순서 | 하는 일 | 설명서 |
| --- | --- | --- |
| 1 | 관리자 화면에 접속합니다 | [관리자 접속과 화면 구성](/admin/access) |
| 2 | 강사 가입과 정보수정 요청을 승인합니다 | [강사 승인 관리](/admin/tutor-approval) |
| 3 | 신청받을 프로그램을 등록하고 수정합니다 | [프로그램 관리](/admin/programs) |
| 4 | 수강 신청을 확정하고 강사를 배정합니다 | [수강 신청 관리와 강사 배정](/admin/applies) |
| 5 | 확정된 강의의 진행 상황을 확인합니다 | [강의 관리](/admin/lectures) |
| 6 | 공지사항, FAQ, 문의를 관리합니다 | [공지사항 · FAQ · 문의관리](/admin/boards) |
| 7 | 회원과 시스템 설정을 관리합니다 | [회원 · 시스템 설정](/admin/settings) |

## 핵심 작업 흐름

관리자 업무 중 **수강 신청을 확정하는 작업**이 가장 중요합니다.
이 작업 한 번으로 여러 처리가 함께 진행되기 때문입니다.

1. **수강 신청 관리**에서 신청 건을 엽니다.
2. 선생님이 제출한 1~3순위 중에서 **일정을 선택**합니다.
3. **강사를 배정**합니다. 여러 명을 배정할 수 있습니다.
4. **견적서를 생성**합니다. 품목, 단가, 수량을 입력합니다.
5. **신청 확정하기**를 누릅니다.

확정 시점에 다음이 함께 처리됩니다.

- 진행 상태가 **수강확정**으로 변경됩니다.
- 강의가 자동으로 생성됩니다.
- 신청자와 배정된 강사에게 안내 메일이 발송됩니다.
- 강사 화면에 강의가 표시되고, 선생님 화면에 강사 정보가 표시됩니다.

자세한 내용은 [수강 신청 관리와 강사 배정](/admin/applies)에 있습니다.
