# 4. 마이페이지에서 관리하기

신청 이후의 모든 일은 마이페이지에서 처리합니다.
오른쪽 위의 **마이페이지**를 누르면 이동합니다.

## 마이페이지 메뉴

| 메뉴 | 내용 |
| --- | --- |
| **수강 신청 내역** | 신청한 건들의 진행 상황을 확인합니다 |
| **관심 프로그램** | 관심 등록한 프로그램을 확인합니다 |
| **나의 문의** | 남긴 문의와 답변을 확인합니다 |
| **계정 정보** | 정보를 확인하고 비밀번호를 변경합니다 |

## 신청 상세 화면

**수강 신청 내역**에서 확인할 신청 건을 누릅니다.
상세 화면은 네 개의 탭과 오른쪽 상태 영역으로 구성되어 있습니다.

| 탭 | 확인할 수 있는 내용 |
| --- | --- |
| **신청 정보** | 제출한 신청 내용 |
| **강의 정보** | 확정된 일정, 배정된 강사, 수업 결과물 |
| **결제 정보** | 견적서, 계약서, 거래명세서 등 서류 |
| **1:1 대화** | 담당자와 주고받는 메시지 |

::: info 이미지 자리 · `teacher/teacher-09-apply-detail-tabs.png`
신청 상세 화면 (탭 네 개와 오른쪽 접수 상태가 함께 보이도록 촬영)
:::

## 접수 상태 확인하기

오른쪽 **접수 상태**에 현재 단계가 표시됩니다.

| 단계 | 의미 |
| --- | --- |
| **접수중** | 담당자가 확인하고 일정, 강사, 견적을 준비하고 있습니다 |
| **수강확정** | 날짜가 확정되고 강사 배정이 완료되었습니다 |

신청이 취소되거나 거절된 경우에는 단계 대신 **신청 취소** 또는 **신청 거절**이 표시됩니다.

### 신청 취소

수강확정 전까지만 오른쪽에 **접수취소** 버튼이 표시됩니다.

1. **접수취소**를 누릅니다.
2. `취소 후에는 되돌릴 수 없습니다.` 확인 창에서 **신청 취소**를 누릅니다.
3. `[인터에듀] 수강신청이 취소되었습니다` 메일이 발송됩니다.

::: danger 수강확정 이후에는 화면에서 취소할 수 없습니다
확정 후 일정 변경이나 취소가 필요한 경우 **1:1 대화**로 담당자에게 알려 주세요.
:::

## 담당자와 상담하기 {#chat}

**1:1 대화** 탭에서 이 신청 건에 대한 대화를 주고받습니다.

1. **1:1 대화** 탭을 누릅니다.
2. 아래 입력란에 내용을 입력합니다.
3. **문의 보내기**를 누릅니다.

- 보낸 메시지는 오른쪽에, 담당자의 메시지는 왼쪽에 **담당자**로 표시됩니다.
- 보낸 시각도 함께 표시됩니다.

::: tip 일정 변경과 인원 변동은 이곳으로 알려 주세요
인원 변동이나 희망 일정 변경 등을 남겨 주시면 기록이 함께 남아 확인이 정확합니다.
:::

::: info 이미지 자리 · `teacher/teacher-10-chat.png`
1:1 대화 탭 (주고받은 메시지가 보이도록 촬영)
:::

## 견적서와 거래명세서 받기 {#documents}

**결제 정보** 탭의 **문서함**에 서류가 등록됩니다.

| 서류 | 설명 |
| --- | --- |
| **견적서** | 담당자가 금액을 산정하여 발행합니다 |
| **계약서** | 필요한 경우 담당자가 등록합니다 |
| **거래명세서** | 수업 진행 후 발행됩니다 |
| **기타** | 그 밖에 담당자가 등록한 파일 |

서류를 누르면 파일이 내려받아집니다.

::: warning 문서가 아직 등록되지 않은 경우
`아직 등록된 문서가 없습니다` 안내가 표시됩니다.
견적서는 담당자가 일정과 인원을 확정한 뒤 발행합니다. 필요하시면 **1:1 대화**로 요청해 주세요.
:::

결제 정보 탭의 문서함 (견적서와 거래명세서가 보이도록 촬영)
:::

## 배정된 강사 확인하기

**강의 정보** 탭은 수강확정 이후에 내용이 표시됩니다.
확정 전에는 `수강 확정 후 표시됩니다` 안내만 표시됩니다.

### 강의 정보

| 항목 | 설명 |
| --- | --- |
| **강의 상태** | 강의시작전, 강의중, 강의종료 |
| **강의 일정** | 확정된 날짜와 시작 시간 |

### 강사 정보

배정된 강사가 카드 형태로 표시됩니다. 한 건에 여러 명이 배정될 수 있습니다.

- 프로필 사진
- 이름
- 전화번호
- 이메일

::: tip 수업 전 연락
수업 당일 동선이나 준비물 확인은 표시된 연락처로 직접 문의하셔도 됩니다.
:::

::: info 이미지 자리 · `teacher/teacher-12-tutor-info.png`
강의 정보 탭의 강사 정보 카드
:::

## 수업 결과물 확인하기 {#results}

**강의 정보** 탭 아래쪽의 **학급별 강의 내역**에서 확인합니다.
수업 종료 후 강사가 자료를 등록하면 이곳에 표시됩니다.

| 자료 | 확인 방법 |
| --- | --- |
| **활동 사진** | 사진을 누르면 크게 열립니다. 창 안에서 내려받을 수 있습니다. |
| **결과보고서** | 항목을 누르면 파일이 내려받아집니다. |

반이 여러 개인 경우 반 이름별로 나뉘어 표시됩니다.

::: warning 자료가 아직 등록되지 않은 경우
`아직 등록된 자료가 없습니다` 안내가 표시됩니다.
강사가 수업 후 자료를 정리하는 데 며칠이 소요될 수 있습니다. 오래 지연되는 경우 **1:1 대화**로 문의해 주세요.
:::

학급별 강의 내역 (활동 사진과 결과보고서가 보이도록 촬영)
:::
