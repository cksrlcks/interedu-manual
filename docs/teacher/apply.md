# 3. 수강 신청하기

신청서는 한 화면으로 되어 있습니다. 위에서 아래로 입력한 뒤 **신청하기**를 누르면 완료됩니다.

신청서로 이동하는 방법은 두 가지입니다.

- 프로그램 상세 화면에서 **수강 신청하기**를 누릅니다.
- 수강바구니에서 프로그램을 선택하고 **선택한 프로그램 신청하기**를 누릅니다.

::: info 이미지 자리 · `teacher/teacher-06-apply-form.png`
수강 신청서 화면 전체 (프로그램 정보 · 신청 정보 입력 · 프로그램 배정 세 영역이 보이도록 촬영)
:::

## 신청서 구성

신청서는 세 부분으로 되어 있습니다.

1. **프로그램 정보** — 무엇을 신청할지 선택합니다.
2. **신청 정보 입력** — 언제, 어디서 진행할지와 연락처를 입력합니다.
3. **프로그램 배정** — 어느 반에 어떤 프로그램을 배정할지 지정합니다.

## 1. 프로그램 정보

신청하려는 프로그램이 목록으로 표시됩니다.

- 제외하려면 해당 프로그램의 **제거**를 누릅니다.
- 추가하려면 **프로그램 추가하기**를 눌러 선택합니다.

::: tip 여러 프로그램을 한 번에 신청할 수 있습니다
반마다 다른 프로그램을 진행하셔도 됩니다. 신청은 한 건으로 묶여서 처리됩니다.
:::

## 2. 신청 정보 입력

### 희망일정 (필수)

**1순위, 2순위, 3순위를 모두 입력**해 주세요.

| 항목 | 설명 |
| --- | --- |
| **1순위 희망 일정** | 가장 원하는 날짜와 시작 시간 |
| **2순위 희망 일정** | 1순위가 어려울 때 진행할 날짜와 시작 시간 |
| **3순위 희망 일정** | 2순위도 어려울 때 진행할 날짜와 시작 시간 |

- 날짜는 달력에서 선택하고, 시간은 `09:00` 형식으로 입력합니다.
- **내일 이후의 날짜**만 선택할 수 있습니다. 오늘과 지난 날짜는 선택되지 않습니다.
- 각 순위는 **날짜와 시간을 함께** 입력해야 합니다. 한쪽만 입력하면 안내 문구가 표시됩니다.

::: warning 세 개의 일정이 모두 필요한 이유
강사 일정이 겹치면 1순위 날짜로 진행이 어려울 수 있습니다.
예비 일정까지 주셔야 담당자가 바로 일정을 확정할 수 있고, 연락이 오가는 시간을 줄일 수 있습니다.
:::

### 신청학급수

**－**와 **＋** 버튼으로 반 개수를 조절합니다. 숫자를 직접 입력하셔도 됩니다.
여기서 지정한 개수만큼 아래 **프로그램 배정**에 입력 줄이 생성됩니다.

### 신청장소 (필수)

수업이 진행될 장소를 입력합니다. 예) `해운대 고등학교`

### 대표 선생님 연락처 (필수)

수업 당일 강사가 연락할 담당 선생님의 전화번호입니다. 예) `010-1234-5678`

::: warning 연락 가능한 번호를 입력해 주세요
이 번호는 배정된 강사에게 그대로 전달됩니다. 수업 당일 연락이 가능한 번호를 입력해 주세요.
:::

### 기타 요청사항

장소 특이사항, 인원 변동 가능성, 준비물 관련 요청 등을 자유롭게 입력합니다. 최대 2000자까지 입력할 수 있습니다.

## 3. 프로그램 배정

반마다 한 줄씩 세 항목을 입력합니다.

| 항목 | 입력 방법 |
| --- | --- |
| **학급** | 반 이름을 최대 20자로 입력합니다. 예) `1학년 1반` |
| **학급인원** | 해당 반의 인원수를 입력합니다. |
| **프로그램 배정** | 위에서 선택한 프로그램 중에서 하나를 지정합니다. |

::: danger 모든 줄에 프로그램을 지정해야 합니다
한 줄이라도 프로그램을 지정하지 않으면 `프로그램을 선택해주세요` 안내가 표시되며 신청이 진행되지 않습니다.
:::

**입력 예시** — 세 개 반에 두 가지 프로그램을 신청하는 경우

| 학급 | 학급인원 | 프로그램 배정 |
| --- | --- | --- |
| 1학년 1반 | 28 | 판화 체험 |
| 1학년 2반 | 30 | 판화 체험 |
| 1학년 3반 | 27 | 금속공예 체험 |

## 신청서 제출

1. 아래쪽의 **신청하기**를 누릅니다.
2. `신청하신 정보로 신청합니다.` 확인 창에서 **신청하기**를 한 번 더 누릅니다.
3. `수강 신청이 완료되었습니다.` 안내가 표시되고 **수강 신청 내역** 화면으로 이동합니다.
4. 가입하신 이메일로 `[인터에듀] 수강신청이 완료되었습니다` 메일이 발송됩니다.

:::

## 신청 이후

담당자가 신청 내용을 확인하고 영업일 기준 24시간 이내에 연락드립니다.
진행 상황은 [마이페이지](/teacher/mypage)에서 언제든지 확인하실 수 있습니다.

모든 입력 규칙은 [입력 규칙 한눈에 보기](/reference/validation)에 정리되어 있습니다.

## 입력 시 확인이 필요한 안내

| 안내 문구 | 확인할 내용 |
| --- | --- |
| `프로그램을 1개 이상 추가해주세요.` | 프로그램 정보 영역이 비어 있습니다. **프로그램 추가하기**로 선택해 주세요. |
| `1순위 희망 일자는 필수입니다.` | 1순위 날짜를 선택하지 않았습니다. |
| `2순위는 일자와 시간을 함께 입력해주세요.` | 날짜만 입력했거나 시간만 입력했습니다. 두 항목을 모두 입력해 주세요. |
| `3순위는 일자와 시간을 함께 입력해주세요.` | 위와 같습니다. |
| `학급명을 입력해주세요` / `최대 20자까지 입력 가능합니다` | 학급명이 비었거나 20자를 넘었습니다. |
| `1명 이상 입력해주세요` | 학급인원이 비었거나 0입니다. |
| `2000자 이내로 입력해주세요.` | 기타 요청사항이 2000자를 넘었습니다. |
| `신청 장소는 필수입니다.` | 신청장소 항목이 비어 있습니다. |
| `대표 선생님 연락처는 필수입니다.` | 연락처 항목이 비어 있습니다. |
| `프로그램을 선택해주세요` | 프로그램 배정에서 지정하지 않은 줄이 있습니다. |
