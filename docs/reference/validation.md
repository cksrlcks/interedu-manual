# 입력 규칙 한눈에 보기

화면에서 실제로 검사하는 값들을 모았습니다.
입력이 막히거나 안내 문구가 표시될 때 이 표에서 조건을 확인하실 수 있습니다.

## 계정 공통

| 항목 | 규칙 |
| --- | --- |
| 아이디 (선생님 · 강사) | **8자 이상**. 상한 없음. 중복확인 필수 |
| 아이디 (관리자) | 최대 20자 |
| 비밀번호 (선생님 · 강사) | 영문 + 숫자 + 특수문자(`!@#$%^&*`) 를 모두 포함한 **8~20자** |
| 비밀번호 (관리자) | 영문 + 숫자 + 특수문자를 각각 1자 이상 포함한 **8자 이상** |
| 이메일 | 이메일 형식. 중복확인 필수 |
| 휴대폰 · 연락처 | `010-1234-5678` 형식 (`숫자3-숫자3또는4-숫자4`) |

::: warning 비밀번호에 쓸 수 있는 특수문자
`! @ # $ % ^ & *` 여덟 개만 사용할 수 있습니다. 그 외 기호를 넣으면 안내 문구가 표시됩니다.
:::

## 선생님 회원가입

| 항목 | 규칙 |
| --- | --- |
| 이름 | 필수 |
| 유형 | **교사** 또는 **일반** 중 선택 (필수) |
| 학교코드 · 학교명 | 유형이 **교사**일 때 필수. 학교 검색으로 자동 입력 |
| 기관명 | 선택 |

## 강사 회원가입

| 항목 | 규칙 |
| --- | --- |
| 이름 · 주소 · 상세 주소 | 필수 |
| 단체명 | 필수 |
| 주요 분야 | **1개 이상** 선택 |
| 은행 · 계좌 번호 | 선택 |
| 학력 · 경력 | 등록하지 않아도 가입됩니다. 다만 **한 줄을 추가하면 그 줄의 모든 칸을 채워야 합니다** |
| 학력 한 줄 | 학력 구분, 학력 상태, 학교명, 전공명, 졸업일자, 정렬 순서 필수 / 부전공명 선택 |
| 경력 한 줄 | 경력 구분, 주관 업체, 경력 일자, 업무 내용, 정렬 순서 필수 |
| 정렬 순서 | **1 이상**의 숫자 |

## 수강 신청

| 항목 | 규칙 |
| --- | --- |
| 희망 일정 | **1순위 · 2순위 · 3순위를 모두 입력**해 주세요. 각 순위는 날짜와 시간을 **함께** 입력해야 합니다 |
| 선택 가능한 날짜 | **내일 이후**. 오늘과 지난 날짜는 선택할 수 없습니다 |
| 시간 | `09:00` 형식 |
| 신청장소 | 필수 |
| 대표 선생님 연락처 | 필수 |
| 기타 요청사항 | 선택. 최대 **2000자** |
| 학급 | **1개 이상**. 각 학급마다 학급명, 학급인원, 프로그램을 모두 지정해야 합니다 |
| 학급명 | 필수. 최대 **20자** |
| 학급인원 | **1명 이상** |

::: tip 2순위와 3순위를 꼭 넣어 주세요
강사 일정이 겹치면 1순위 날짜로 진행이 어려울 수 있습니다.
세 개의 희망 일정을 모두 주셔야 일정 확정이 지연되지 않습니다.
:::
