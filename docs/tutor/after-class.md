# 5. 강의 후 정리

수업이 종료되면 **강의 관리**에서 해당 강의의 상세 화면으로 이동하여
**활동 내역 입력** 영역에서 결과를 정리합니다.

이곳에 등록한 내용은 **신청한 선생님의 마이페이지에도 그대로 표시됩니다.**

![활동 내역 입력 영역](/images/tutor/tutor-10-activity-input.png)

## 반별로 입력합니다

학급이 세 개면 입력란도 세 개가 표시되며, 각 입력란 위에 반 이름이 표시됩니다.
반마다 참여인원과 사진이 다르므로 각각 입력해 주세요.

## 1단계. 참여인원 입력

**참여인원** 칸에 실제로 수업에 참여한 인원수를 숫자로 입력합니다.
신청 인원과 다를 수 있으므로 실제 참여한 인원을 기준으로 입력해 주세요.

## 2단계. 활동 사진 업로드

**활동 사진** 영역을 눌러 사진을 선택합니다.

| 항목 | 조건 |
| --- | --- |
| 파일 형식 | **PNG 또는 JPG** |
| 최대 장수 | 한 반당 **5장** |

- 여러 장을 한 번에 선택할 수 있습니다.
- 잘못 선택한 사진은 사진 위의 삭제 아이콘으로 제거합니다.
- 이미 등록된 사진도 같은 방법으로 삭제할 수 있습니다.

::: warning 지원하지 않는 형식
HEIC(아이폰 기본 형식)나 PDF는 업로드되지 않으며 `활동 사진은 PNG 또는 JPG 파일만 업로드할 수 있습니다.` 안내가 표시됩니다.
아이폰을 사용하시는 경우 **설정 → 카메라 → 포맷 → 높은 호환성**으로 변경하거나, 사진을 JPG로 변환한 뒤 업로드해 주세요.
:::

## 3단계. 결과보고서 생성

**결과보고서** 줄 오른쪽의 **자동 생성하기** 버튼을 누르면
입력한 참여인원과 사진을 바탕으로 보고서가 자동으로 생성됩니다.

::: danger 생성 전에 두 가지를 먼저 확인해 주세요
1. **참여인원**을 입력했는지 확인합니다. 비어 있으면 `참여인원을 입력하세요.` 안내가 표시됩니다.
2. **활동 사진**을 업로드했는지 확인합니다. 없으면 `활동사진을 먼저 업로드하세요.` 안내가 표시됩니다.
:::

**자동 생성하기**를 누르면 `결과보고서 생성을 요청했습니다. 잠시 후 새로고침해 주세요.` 안내가 표시됩니다.
잠시 후 화면을 새로고침(F5)하면 보고서 파일이 목록에 나타납니다.

### 보고서를 직접 업로드하는 경우

자동 생성 대신 직접 작성한 파일을 업로드할 수 있습니다.
**결과보고서** 영역에서 PDF 파일을 선택해 업로드해 주세요.

## 4단계. 저장

::: danger 마지막에 반드시 저장해 주세요
참여인원과 새로 선택한 사진, 보고서는 오른쪽 **저장** 영역의 **저장하기**를 눌러야 반영됩니다.
저장하지 않고 화면을 벗어나면 입력한 내용이 사라집니다.
:::

저장이 완료되면 `저장되었습니다.` 안내가 표시됩니다.

## 전체 순서

반마다 다음 순서를 반복합니다.

1. 참여인원을 입력합니다.
2. 활동 사진을 업로드합니다. (PNG 또는 JPG, 반당 최대 5장)
3. **자동 생성하기**를 누르고, 잠시 후 새로고침하여 보고서를 확인합니다.
4. 오른쪽 **저장하기**를 누릅니다.

## 선생님 화면에서 보이는 모습

선생님이 마이페이지에서 신청 내역의 **강의 정보** 탭을 열면
반별로 활동 사진과 결과보고서가 표시됩니다.
사진은 수업 분위기가 잘 드러나는 것으로 선택해 주세요.
