# 4. 강의 관리

선생님의 수강 신청이 관리자에 의해 확정되고 해당 신청에 강사로 배정되면,
왼쪽 메뉴 **강의 관리**에 강의가 표시됩니다.

::: tip 강의는 자동으로 생성됩니다
강의는 관리자가 신청을 확정하는 시점에 자동으로 생성됩니다.
강사가 직접 강의를 등록할 필요는 없으며, 배정된 강의를 확인하고 준비하는 것이 강사의 역할입니다.
:::

## 대시보드에서 일정 확인하기

왼쪽 메뉴 **대시보드**에는 월별 달력이 있습니다.
배정된 강의가 날짜에 표시되므로 한 달 일정을 한 번에 확인할 수 있습니다.
달력 위쪽의 화살표로 이전 달과 다음 달로 이동합니다.

::: info 이미지 자리 · `tutor/tutor-07-schedule-calendar.png`
대시보드의 월별 강의 일정 달력
:::

## 강의 목록

왼쪽 메뉴 **강의 관리**를 누르면 배정된 강의가 목록으로 표시됩니다.
확인할 강의의 **상세** 버튼을 누릅니다.

## 강의 상세 화면

강의 상세는 다음 순서로 구성되어 있습니다.

### 신청자 정보

수업을 신청한 선생님의 이름, 이메일, 전화번호, 아이디입니다.

### 신청 정보

수업 조건이 정리되어 있는 영역입니다.

| 항목 | 설명 |
| --- | --- |
| 신청 번호 | 문의 시 이 번호를 알려 주시면 빠르게 확인할 수 있습니다 |
| 신청 프로그램 | 진행할 프로그램 이름 |
| 신청 학급수 · 학급 상세 | 반 이름과 반별 인원 |
| 총 인원 | 전체 인원 |
| 신청 장소 | 수업이 진행될 학교 또는 기관 |
| **확정일자** | 관리자가 확정한 수업 날짜와 시작 시간 |
| **대표 선생님 연락처** | 수업 당일 연락할 담당 선생님 전화번호 |
| 추가 문의 | 선생님이 남긴 요청사항 |

::: info 이미지 자리 · `tutor/tutor-08-lecture-detail.png`
강의 상세 화면 위쪽 (신청자 정보와 신청 정보)
:::

### 강사 정보

같은 강의에 함께 배정된 강사가 표시됩니다.
한 강의에 여러 명의 강사가 배정될 수 있습니다.

## 수업 전 준비 서류 {#materials}

강의 상세 중간의 **강사 준비물** 영역에서 수업 전에 필요한 서류를 처리합니다.

::: info 이미지 자리 · `tutor/tutor-09-materials.png`
강사 준비물 영역 전체 (양식 목록과 운영확인서 · 강사카드 목록)
:::

### 각종 양식 및 링크

| 서류 | 처리 방법 |
| --- | --- |
| **성범죄 경력 및 아동학대관련범죄 전력 조회 동의서** | 오른쪽 **양식 다운로드**를 눌러 한글(.hwp) 파일을 받습니다. 작성과 서명 후 아래 **문서함**에 업로드하거나 담당자에게 전달합니다. |

::: warning 학교 수업에 필수인 서류입니다
동의서는 수업 전에 미리 준비해 주셔야 합니다. 수업 당일에는 처리가 어렵습니다.
:::

### 운영확인서와 강사카드 {#cert-files}

프로그램별로 한 줄씩 표시되며, 각 줄 오른쪽에 두 개의 버튼이 있습니다.

| 버튼 | 설명 |
| --- | --- |
| **운영확인서 다운로드** | 관리자가 수강을 확정하면 자동으로 생성됩니다. 눌러서 내려받습니다. |
| **강사카드 생성** → **강사카드 다운로드** | 처음에는 생성 버튼만 표시됩니다. 누르면 프로필 정보로 강사카드가 생성됩니다. |

::: tip 생성 후에는 화면을 새로고침해 주세요
**강사카드 생성**을 누르면 `강사카드 생성을 요청했습니다. 잠시 후 새로고침해 주세요.` 안내가 표시됩니다.
잠시 후 화면을 새로고침(F5)하면 **강사카드 다운로드** 버튼으로 바뀝니다.
:::

::: warning 운영확인서가 생성되지 않았다는 안내가 표시되는 경우
아직 서류가 준비되기 전입니다. 잠시 후 다시 시도하시고, 계속 같은 안내가 표시되면 담당자에게 문의해 주세요.
:::

### 강사카드 사진

강사카드에는 **강사 정보**에 등록한 프로필 사진이 사용됩니다.
사진이 없거나 변경이 필요한 경우 [강사 정보 수정](/tutor/profile)에서 먼저 프로필 사진을 등록해 주세요.
프로필 사진도 관리자 승인 후에 반영됩니다.

## 문서함

강의 상세 아래쪽의 **문서함**에서 그 밖의 서류를 주고받습니다.

- **파일 업로드** 버튼을 누르고 파일을 선택한 뒤 **업로드**를 누릅니다.
- 업로드된 파일은 오른쪽 내려받기 아이콘으로 다시 받을 수 있습니다.
- 삭제 아이콘으로 파일을 삭제할 수 있으며, 확인 창이 한 번 표시됩니다.

서명한 동의서나 학교에서 요청한 추가 서류를 이곳에 업로드합니다.

## 강의 단계 확인

오른쪽 **강의 단계**에 현재 상태가 표시됩니다.

| 단계 | 의미 |
| --- | --- |
| **강의시작전** | 아직 수업 날짜가 되지 않았습니다 |
| **강의중** | 수업 진행 기간입니다 |
| **강의종료** | 수업이 종료되었습니다 |

수업이 종료되었다면 [강의 후 정리](/tutor/after-class)를 확인해 주세요.
