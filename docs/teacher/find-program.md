# 2. 수업 찾기

상단 메뉴 **프로그램 탐색**을 누르면 신청할 수 있는 수업이 모두 표시됩니다.

![프로그램 목록 화면](/images/teacher/teacher-03-program-list.png)

## 분류 선택

목록 위쪽 탭에서 수업 종류를 선택합니다.

| 탭 | 내용 |
| --- | --- |
| **찾아가는프로그램** | 강사가 학교나 기관으로 방문하여 진행하는 수업 |
| **현장학습** | 학생들이 현장으로 이동하여 참여하는 수업 |

## 이름으로 검색

검색창에 프로그램 이름의 일부를 입력하면 목록이 바로 걸러집니다.
정확한 이름을 몰라도 한두 단어만 입력하시면 됩니다.

## 조건으로 검색

왼쪽 영역(모바일에서는 **필터** 버튼)에서 조건을 선택합니다.

| 구분 | 선택 항목 |
| --- | --- |
| **대상별** | 초등학교, 중학교 등 |
| **수업시간** | 60분 이하, 70~80분, 90분 이상 |

- 여러 조건을 동시에 선택할 수 있습니다.
- **초기화**를 누르면 선택한 조건이 모두 해제됩니다.

::: tip 검색 결과를 공유할 수 있습니다
검색어와 필터 조건은 주소(URL)에 저장됩니다.
조건을 적용한 화면의 주소를 복사해 전달하시면 같은 목록이 그대로 열립니다.
:::

## 프로그램 상세

목록에서 카드를 누르면 상세 화면으로 이동합니다.

![프로그램 상세 화면](/images/teacher/teacher-04-program-detail.png)

### 확인할 수 있는 정보

| 항목 | 설명 |
| --- | --- |
| **교육 대상** | 어떤 학년과 대상에 맞는 수업인지 확인합니다 |
| **교육 시간** | 한 차시 진행 시간(분) |
| **재료비** | 1인당 재료비 |
| **강사비** | 강사 비용 |
| 프로그램 개요 · 내용 | 수업 진행 방식 |
| 교육 사진 | 실제 수업 장면. 눌러서 크게 볼 수 있습니다 |

::: warning 표시된 금액은 참고용입니다
실제 청구 금액은 인원과 학급수에 따라 달라집니다.
정확한 금액은 신청 후 담당자가 발행하는 **견적서**로 확인해 주세요.
:::

### 오른쪽 버튼

| 버튼 | 기능 |
| --- | --- |
| **수강 신청하기** | 이 프로그램으로 바로 신청서를 작성합니다 |
| **수강바구니 담기** | 나중에 한 번에 신청하기 위해 담아 둡니다 |
| 관심 등록(하트) | **관심 프로그램**으로 저장합니다 |
| **문의하기** | 이 프로그램에 대한 문의를 남깁니다 |
| **공유** | 링크를 복사하거나 카카오톡으로 공유합니다 |

::: tip 로그인이 필요합니다
신청, 수강바구니, 관심 등록, 문의는 로그인 후 이용할 수 있습니다.
로그인하지 않은 상태라면 안내 창이 표시되며, **로그인하기**를 누르면 로그인 후 원래 화면으로 돌아옵니다.
:::

## 수강바구니

여러 프로그램을 한 번에 신청하실 때 수강바구니를 이용하면 편리합니다.

1. 원하는 프로그램마다 **수강바구니 담기**를 누릅니다.
2. 상단의 수강바구니 아이콘을 누릅니다.
3. 신청할 프로그램을 선택합니다. **전체선택**도 이용할 수 있습니다.
4. **선택한 프로그램 신청하기**를 누르면 신청서로 이동합니다.

- 프로그램을 빼실 때는 **제거**를 누릅니다. 확인 창이 한 번 표시됩니다.
- 수강바구니 안에서도 **프로그램 추가**로 더 담을 수 있습니다.

![수강바구니 화면](/images/teacher/teacher-05-cart.png)

## 관심 프로그램

관심 등록(하트)을 누른 프로그램은 **마이페이지 → 관심 프로그램**에 모입니다.
바로 신청하지 않더라도 나중에 다시 찾기 쉽도록 저장해 두는 기능입니다.
