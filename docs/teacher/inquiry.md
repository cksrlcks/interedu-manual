# 5. 문의하기

문의 방법은 두 가지입니다. 상황에 따라 선택해 주세요.

| 상황 | 문의 위치 |
| --- | --- |
| 이미 신청한 건에 대한 문의 (일정 변경, 인원 변동 등) | 신청 상세의 **1:1 대화** 탭 |
| 신청 전이거나 신청과 관계없는 일반 문의 | 마이페이지의 **나의 문의** |

## 신청 건에 대한 문의

마이페이지에서 **수강 신청 내역**으로 이동하여 해당 신청을 선택한 뒤 **1:1 대화** 탭을 이용합니다.
자세한 방법은 [담당자와 상담하기](/teacher/mypage#chat)에 있습니다.

## 일반 문의

### 문의 등록

1. 마이페이지에서 **나의 문의**로 이동합니다.
2. **문의하기** 버튼을 누릅니다.
3. **제목**을 입력합니다. 최대 200자까지 입력할 수 있습니다.
4. **문의 내용**을 입력합니다. 최대 2000자까지 입력할 수 있습니다.
5. **문의 등록**을 누릅니다.

프로그램 상세 화면의 **문의하기** 버튼을 눌러도 같은 화면으로 이동합니다.

![문의 작성 화면](/images/teacher/teacher-14-inquiry-write.png)

### 답변 확인

- 답변이 등록되면 `[인터에듀] 문의에 답변이 작성되었습니다` 메일이 발송됩니다.
- **나의 문의** 목록에서 해당 글을 누르면 질문과 답변을 함께 확인할 수 있습니다.

### 문의 수정

답변이 등록되기 전이라면 작성한 문의를 수정할 수 있습니다.
글 상세 화면에서 **수정**을 누르고 내용을 변경한 뒤 **문의 수정**을 누릅니다.

## 자주 묻는 질문 확인

상단 메뉴 **자주 묻는 질문**에 자주 문의되는 내용이 정리되어 있습니다.
공통, 신청자, 강사, 계약, S2B이용, 정산으로 분류되어 있으니 문의 전에 먼저 확인해 보시기 바랍니다.
