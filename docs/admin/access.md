# 1. 관리자 접속과 화면 구성

## 접속 주소

| 화면 | 주소 |
| --- | --- |
| 관리자 로그인 | **`https://interedu.ai.kr/admin/sign-in`** |
| 관리자 첫 화면 | `https://interedu.ai.kr/admin` |

::: warning 관리자 계정은 회원가입으로 만들 수 없습니다
관리자 계정은 기존 관리자가 [관리자관리](/admin/settings#admins)에서 생성합니다.
별도의 회원가입 화면이 없습니다.
:::

## 로그인

아이디와 비밀번호를 입력하고 **로그인**을 누릅니다.

![관리자 로그인 화면](/images/admin/admin-01-signin.png)

## 화면 구성

왼쪽에 메뉴가 항상 표시되며, 오른쪽이 작업 영역입니다.
메뉴는 업무별로 그룹화되어 있습니다.

| 그룹 | 메뉴 | 내용 |
| --- | --- | --- |
| **프로그램** | 프로그램 관리 | 신청받을 프로그램을 등록, 수정, 삭제합니다 |
| **강사관리** | 인력풀 관리 | 승인된 강사 목록을 확인합니다 |
| | 강사신청 관리 | 가입과 정보수정 요청을 승인하거나 거절합니다 |
| **신청관리** | 수강 신청 관리 | 접수된 신청을 확인하고 일정 확정, 강사 배정, 견적서와 거래명세서를 처리합니다 |
| | 강의 관리 | 확정된 신청에서 생성된 강의를 확인합니다 |
| **운영관리** | 공지사항 | 홈페이지 공지를 작성합니다 |
| | FAQ | 자주 묻는 질문을 작성합니다 |
| | 문의관리 | 회원 문의에 답변합니다 |
| **계정관리** | 회원관리 | 가입한 회원 목록을 확인합니다 |
| | 관리자관리 | 관리자 계정을 추가합니다 |
| **시스템** | 게시판 관리 | 게시판을 생성하고 설정합니다 |
| | 카테고리 관리 | 프로그램 카테고리를 관리합니다 |
| | 공통코드 관리 | 선택 목록에 사용되는 코드를 관리합니다 |

![관리자 첫 화면](/images/admin/admin-02-layout.png)

## 화면 공통 규칙

관리자 화면은 대부분 동일한 구조이므로, 한 화면의 사용법을 익히면 나머지도 동일하게 사용하실 수 있습니다.

### 목록 화면

- 표 형태로 표시되며, 오른쪽 **관리** 칸에 **상세**, **수정**, **삭제** 버튼이 있습니다.
- 새로 등록할 때는 오른쪽 위의 **등록** 버튼을 누릅니다.

### 상세 · 수정 화면

- 왼쪽 넓은 영역에서 내용을 확인하거나 입력합니다.
- 오른쪽 좁은 영역에 진행 단계, **저장** 또는 **삭제** 버튼, **목록으로** 버튼이 있습니다.

::: tip 저장 버튼은 항상 오른쪽에 있습니다
내용을 수정한 뒤 오른쪽의 **저장** 또는 **등록**, **수정** 버튼을 눌러야 반영됩니다.
:::

### 삭제 시 확인 창

삭제는 대부분 되돌릴 수 없으므로 확인 창이 한 번 더 표시됩니다.
내용을 확인한 뒤 진행해 주세요.

## 로그아웃

왼쪽 메뉴 위쪽의 로그아웃 아이콘을 누릅니다.
