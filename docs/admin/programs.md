# 3. 프로그램 관리

홈페이지에서 선생님들이 확인하고 신청하는 수업 목록을 관리합니다.

왼쪽 메뉴에서 **프로그램 → 프로그램 관리**를 누릅니다.

::: info 이미지 자리 · `admin/admin-05-programs.png`
프로그램 관리 목록 화면
:::

## 목록 화면

| 항목 | 내용 |
| --- | --- |
| 번호 | 프로그램 번호 |
| 프로그램명 | 홈페이지에 표시되는 이름 |
| 카테고리 | 상위와 하위 분류 |
| 등록일 | 등록한 날짜 |
| 관리 | **수정**, **삭제** |

새로 등록할 때는 오른쪽 위의 **프로그램 등록**을 누릅니다.

## 프로그램 등록

입력 항목은 등록과 수정이 동일합니다.

::: info 이미지 자리 · `admin/admin-06-program-form.png`
프로그램 등록 화면 전체
:::

### 기본 정보 {#basic-info}

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| **프로그램명** | 필수 | 목록과 상세 화면에 표시되는 이름입니다. 최대 **200자** |
| **짧은 설명** | 필수 | 이름 아래에 표시되는 한 줄 소개입니다. 최대 **200자** |
| **상위 카테고리** | — | 찾아가는프로그램, 현장학습 등 큰 분류입니다 |
| **하위 카테고리** | 필수 | 상위 카테고리를 선택하면 목록이 표시됩니다 |
| **프로그램 대상** | 필수 | 초등학교, 중학교 등입니다. 선생님 화면의 대상별 필터에 사용됩니다 |
| **프로그램 시간 (분)** | 필수 | **1분 이상**의 숫자를 입력합니다. 선생님 화면의 수업시간 필터에 사용됩니다 |
| **강사비 (원)** | 선택 | 견적서 작성 시 기본값으로 사용됩니다 |
| **재료비 (원)** | 선택 | 견적서 작성 시 기본값으로 사용됩니다 |

::: warning 카테고리는 순서대로 선택합니다
상위 카테고리를 먼저 선택하지 않으면 하위 카테고리 목록이 표시되지 않습니다.
새로운 분류가 필요한 경우 [카테고리 관리](/admin/settings#categories)에서 먼저 추가해 주세요.
:::

### 프로그램 개요 (필수)

라벨과 내용을 한 쌍으로 여러 줄 입력하는 방식입니다.
상세 화면에서 표 형태로 정리되어 표시되며, **최소 한 줄은 입력해야 등록됩니다.**

입력 예시는 다음과 같습니다.

| 라벨 | 내용 |
| --- | --- |
| 준비물 | 학교에서 준비할 사항 없음 |
| 진행 방식 | 2인 1조 실습 |
| 결과물 | 판화 작품 1점 |

### 프로그램 내용 (필수)

수업을 자세히 설명하는 본문입니다.
블록 편집기를 사용하여 문단과 표를 함께 구성할 수 있습니다.

### 요청 사항 (선택)

학교에 미리 요청할 사항을 입력합니다. 책상 배치, 수돗가 필요 여부 등입니다.

### 사진

| 항목 | 설명 |
| --- | --- |
| **썸네일 사진** | 1장입니다. 목록과 상세 화면 상단에 표시되는 대표 사진입니다 |
| **교육 사진** | 최대 5장입니다. 상세 화면 아래쪽에 갤러리로 표시됩니다 |

::: tip 썸네일은 정사각형 비율을 권장합니다
목록 카드와 상세 화면 모두 정사각형 영역에 맞춰 표시됩니다. 주요 내용이 가운데에 오도록 편집한 뒤 등록해 주세요.
:::

## 저장

오른쪽 **저장** 영역의 **등록** 버튼을 누릅니다. 수정 시에는 **수정** 버튼이 표시됩니다.
**취소**를 누르면 목록으로 돌아갑니다.

## 수정과 삭제

- 목록에서 **수정**을 누르고 내용을 변경한 뒤 오른쪽 **수정**을 누릅니다.
- 목록에서 **삭제**를 누르고 `프로그램을 삭제하시겠습니까?` 확인 창에서 진행합니다.

::: danger 신청 이력이 있는 프로그램 삭제
신청 내역과 강의에서 해당 프로그램을 참조하고 있을 수 있습니다.
더 이상 신청을 받지 않으려는 목적이라면 삭제 대신 카테고리 정리를 검토하시거나 담당자와 상의해 주세요.
:::
