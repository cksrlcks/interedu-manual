# 선생님 설명서 시작하기

이 설명서는 학교나 기관에서 수업을 신청하시는 선생님을 위한 안내서입니다.

## 선생님이 하는 일

| 순서 | 하는 일 | 설명서 |
| --- | --- | --- |
| 1 | 홈페이지에 접속하고 회원가입합니다 | [홈페이지 접속과 회원가입](/teacher/access) |
| 2 | 원하는 수업을 찾습니다 | [수업 찾기](/teacher/find-program) |
| 3 | 수강 신청서를 작성해 제출합니다 | [수강 신청하기](/teacher/apply) |
| 4 | 진행 상황을 확인하고 서류를 받습니다 | [마이페이지에서 관리하기](/teacher/mypage) |
| 5 | 궁금한 점을 문의합니다 | [문의하기](/teacher/inquiry) |

## 신청 후 진행 과정

1. 선생님이 수강 신청서를 제출합니다. 이때 진행 상태는 **접수중**입니다.
2. 담당자가 신청 내용을 확인합니다.
3. 희망 일정 중 하나로 날짜를 확정하고, 강사를 배정하고, 견적서를 발행합니다.
4. 신청이 확정되면 진행 상태가 **수강확정**으로 바뀌고 안내 메일이 발송됩니다.
5. 마이페이지에서 배정된 강사와 확정 일정을 확인할 수 있습니다.
6. 수업이 진행됩니다.
7. 강사가 등록한 수업 사진과 결과보고서를 마이페이지에서 확인할 수 있습니다.

::: tip 신청서 제출 후 연락 시점
신청서를 제출하시면 영업일 기준 24시간 이내에 담당자가 연락드립니다.
:::

## 홈페이지 화면 구성

홈페이지 상단 메뉴는 다음과 같습니다.

| 메뉴 | 내용 |
| --- | --- |
| **프로그램 탐색** | 신청할 수 있는 모든 수업을 확인합니다 |
| **함께하는 기관들** | 인터에듀와 함께하는 공방과 기관을 소개합니다 |
| **자주 묻는 질문** | 자주 문의되는 내용을 모아 두었습니다 |
| 수강바구니 | 관심 있는 프로그램을 담아 두는 곳입니다 |
| 로그인 · 마이페이지 | 신청 내역을 관리하는 곳입니다 |
