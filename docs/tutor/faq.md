# 강사 자주 묻는 질문

궁금한 항목을 누르면 답변이 펼쳐집니다.

## 가입과 로그인

::: details 가입했는데 로그인이 되지 않습니다
관리자 승인이 완료되어야 로그인할 수 있습니다.
승인 상태가 **처리완료**로 변경되기 전에는 아이디와 비밀번호가 일치해도 로그인되지 않습니다.

자세한 내용은 [승인 절차](/tutor/signup#approval)를 확인해 주세요.
:::

::: details 홈페이지에서 강사 계정으로 로그인되지 않습니다
강사는 접속 주소가 다릅니다. `interedu.ai.kr/tutor/sign-in`으로 접속해 주세요.

홈페이지 첫 화면의 로그인은 수업을 신청하는 선생님을 위한 것입니다.
:::

::: details 아이디 중복확인을 눌렀는데 다음 버튼이 활성화되지 않습니다
중복확인 이후 아이디나 이메일을 수정하면 확인이 해제됩니다.
**중복확인**을 다시 눌러 사용 가능 안내를 받아 주세요.
:::

::: details 비밀번호 재설정 메일이 오지 않습니다
먼저 스팸메일함을 확인해 주세요.
그래도 없다면 가입 시 입력한 이메일 주소가 맞는지 확인이 필요합니다.
:::

## 정보 수정

::: details 저장했는데 정보가 변경되지 않았습니다
강사 정보는 저장 시 관리자에게 수정 요청이 접수되고, 승인 후에 반영됩니다.

화면 오른쪽 **수정 요청 내역**에서 처리 상태를 확인해 주세요.
:::

::: details 요청을 잘못 보냈습니다
**접수됨** 또는 **처리중** 상태라면 **수정 요청 내역**에서 취소할 수 있습니다.

이미 **처리완료**된 요청은 취소할 수 없으므로, 내용을 다시 수정해 새 요청을 보내 주세요.
:::

::: details 이름이나 연락처를 바꾸고 싶습니다
이 항목은 강사 정보 화면에서 변경할 수 없습니다.
인터에듀 담당자에게 문의해 주세요.
:::

## 강의

::: details 강의 관리에 아무 내용도 표시되지 않습니다
아직 배정된 강의가 없는 상태입니다.
관리자가 신청을 확정하고 강사를 배정하면 목록에 표시됩니다.
:::

::: details 강사카드 다운로드 버튼이 보이지 않습니다
아직 생성되지 않은 상태입니다.
**강사카드 생성**을 먼저 누르고 잠시 후 화면을 새로고침(F5)해 주세요.
:::

::: details 운영확인서가 생성되지 않았다는 안내가 표시됩니다
서류가 준비되기 전입니다.
잠시 후 다시 시도하시고, 계속 같은 안내가 표시되면 담당자에게 문의해 주세요.
:::

::: details 강사카드 사진을 변경하고 싶습니다
**강사 정보**에서 프로필 사진을 변경하고 승인을 받은 뒤, 강사카드를 다시 생성해 주세요.
:::

## 수업 후

::: details 사진이 업로드되지 않습니다
PNG 또는 JPG 형식만 업로드할 수 있으며, 한 반당 5장까지 가능합니다.

아이폰에서 촬영한 HEIC 사진은 업로드되지 않습니다.
**설정 → 카메라 → 포맷 → 높은 호환성**으로 변경하거나, 사진을 JPG로 변환한 뒤 업로드해 주세요.
:::

::: details 자동 생성하기를 눌렀는데 보고서가 보이지 않습니다
생성에 시간이 소요됩니다. 잠시 후 화면을 새로고침(F5)해 주세요.

참여인원이나 활동 사진이 비어 있으면 생성되지 않으니 두 항목을 먼저 확인해 주세요.
:::

::: details 입력한 참여인원이 저장되지 않았습니다
오른쪽 **저장하기**를 눌러야 반영됩니다.

반을 여러 개 입력한 경우에도 **저장하기** 한 번으로 모두 저장됩니다.
:::
